Basics

  • Product: a generative media API aggregation platform (images, video, audio); one x-api-key calls 100 to 500+ third-party models (Veo, Kling, Seedance, Flux, Midjourney, Suno, Runway, Wan, etc.). It also has a playground, a workflow editor, Agents, MCP, CLI, and white-label service. Pay per call, no subscription. Positioned as the 'lowest-price API', frequently discounting a given model (e.g. Seedance 2.5 at 28% off).
  • Company: Vadoo Internet Services Private Limited, Bangalore, India, incorporated 2020-05-23, started in 2019. Founders Anil Chandra Naidu Matcha and Ankur Singh. The early products were vadoo.tv video hosting and P2P video distribution, later moving into AI video generation tools.
  • Funding: small early investments from Entrepreneur First, JioGenNext and others, roughly $55K-80K in total (The Company Check / CB Insights); no public funding since.
  • Launch: muapi.ai domain registered 2025-04-10; earliest Wayback snapshot 2025-07-08.

Growth loop

Evidence:

  • Open-source-alternative repos serve as bait, with the backend tied to muapi: the README carries a 'Powered by MuAPI' badge, links carry utm_source=github, and a muapi key is needed to get the project running.
  • White-label loop: the README pitches directly 'sell this open-source app to your clients as your own branded AI studio', white-label from $49/month, with the markup going to the developer. Downstream entrepreneurs become muapi's distribution channel, and each generation by their end users consumes muapi credit.
  • Referral program: the referrer gets 10% of the referee's first top-up (paid as credit, with a 15-day hold and a $500 monthly cap), and the referee gets an extra 5% on the first top-up.
  • For every hot new model, an API wrapper repo and a model landing page (a 'coming soon' page like muapi.ai/kling-4) are put up ahead of time to capture search traffic.

Speculation:

  • The main countries are India and social sources are mainly YouTube, which may relate to Indian AI-tutorial YouTubers demoing 'cheap Veo/Kling APIs' and the open-source projects; no specific videos were found.
  • Checkout visits are steady at about 39K per month, which suggests it has entered a stable top-up and repeat-purchase phase.

Revenue and scale clues

  • Usage-based billing, no public MRR or user count. White-label from $49/month.
  • GitHub assets: Open-Generative-AI has about 30.8K stars; the personal account and the SamurAIGPT organization together have 50K+ stars.
  • The team is very small (early funding under $100K), and no public revenue figures.

Confidence and gaps

  • The company ownership and the GitHub acquisition method have first-hand evidence (official about page, GitHub API, READMEs), so credibility is high.
  • Gaps: founder public interviews, muapi's real revenue, the star growth curve of each repo (the stargazers API requires login), and the exact month of takeoff were not found. Reddit scraping was blocked.
