60fps began in 2022 when a small team making product promo videos wanted to collect other products' trailers. In 2023 it first became a "product ads / landing pages / motion inspiration library" whose Product Hunt launch got almost no response (3 votes). It then narrowed to a "recorded-screen library of interaction and motion details in top iOS apps" (now 2,110 shots across 494 apps), with the X account @60fpsdesign (opened 2023-06, now about 131k followers) posting a short app-motion clip every day as its main venue; designers repost and save on X, then come to the site to search by app/gesture/component. In 2025 it added 1,800+ shots in a year; in 2026 it built an iPhone screen-recording mockup tool and an MCP/Claude Code plugin, and charges $15/month per seat for PRO through Gumroad.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: a UI/UX motion and interaction detail library (shots, apps, app sites, motion, storyboards, snippets, glossary), free to browse; PRO is $15/month or $150/year per seat (paid via Gumroad); there is also an MCP plan (priced separately, price not public) and mockup.60fps.design (wraps screen recordings in an iPhone frame); on GitHub there is a plugin that goes "describe a motion → search 2,000+ iOS interaction snippets → generate SwiftUI", supporting Claude Code/Cursor/Codex/Gemini CLI.
  • Who runs it: the site and Substack use only "we / design nerds" and give no founder names; no team members were found.
  • Launch timing: the /why page says it started in 2022; the earliest Wayback snapshot is 2023-10-16 (www.60fps.design, tagline "The best of web ads, interface, motion and interaction design", with content being product ad films from Google, Linear, Notion, Calendly and others, tagged by views, duration, soundtrack and style); the Product Hunt product page shows a 2023 launch; the X account was registered 2023-06-20. The domain RDAP lookup failed (.design suffix).
  • Channels (profile file): non-brand search about 15.4% (camera zoom ui animation, mobile ui design, etc.), social 7.7% (X, Pinterest); India 17%, US 15%, Brazil 10.7%.
  • Social assets: X @60fpsdesign 131,067 followers, 4,791 tweets; Instagram @60fps.design 2,134 followers, 348 posts; Threads, Pinterest and Substack accounts too.

Growth loop

Evidence:

  • Content-account operations: X posts an app interaction recording every day (4,791 tweets, 131k followers), each tweet carrying a 60fps.design link; also posts on Instagram, Threads, Pinterest.
  • Listings in design resource directories and media (Abduzeedo, usetools.design, designeng.tools, uiuxshowcase) bring backlinks.
  • Long-tail search: shot pages are named "app name + action + component" (e.g. openai-dots-intro-mascot-animation), with non-brand search about 15%.

Speculation:

  • The 2026 MCP/Claude Code plugin rides the AI coding tools wave to spread to engineers.
  • The content itself is screen recordings of other apps, so it is "curation + distribution"; follower growth relies on the featured apps' teams and designers reposting (the year-end post specifically thanks "every team, founder, and developer").

Revenue and scale clues

  • PRO is $15/month per seat, paid via Gumroad; the number of paying users was not found.
  • Scale references: X 131k followers; 2,110 shots / 494 apps on the site.

Confidence and gaps

  • Written from scratch for a new site. The useful search results were Substack, X tweets, Abduzeedo and directory sites; Wayback snapshots, the Product Hunt page, the GitHub API and the fxtwitter API were also used for evidence.
  • The founders' identity, the X follower growth timeline and the number of paying users were not found; the takeoff year of 2025 is inferred from "in 2025 it pivoted to an iOS interaction library with heavy updates + the year-end post", and the launch method is filled in as "Not found".
