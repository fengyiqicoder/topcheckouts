Basics

  • Product: Umbrella game-cheat subscription (mainly Dota 2: auto last-hit, map vision, skin changer, auto hook, 800+ features; also Deadlock, CS2, Minecraft). Lua 5.4 scripting API (UC.Zone API v2, GitBook docs, GitHub mirror maintained by community members), cloud sharing of configs/themes.
  • Operator: not public; servers in Moscow (Safe Value Limited), used Russia's Cloud-Shield for DDoS protection in 2018, payments via Anypay. Channels: Telegram, VK, Discord (Umbrella server about 32K members), YouTube.
  • Pricing: free trial (page says 7 days / title says 10 days) + monthly / six-monthly plans (prices not shown on the pricing page).
  • Domain: uc.zone registered 2017-11-07 (RDAP, registrar 101domain).
  • Traffic: Russia 61%, Poland 6.5%, Ukraine 6.4%; direct 60%, search 36% (almost entirely product names like "umbrella" and "амбрелла"); referrals from vk.ru and funpay.com.
  • Note: cheats violate game terms of service; this report only documents the growth path.

Growth loop

Evidence:

  • Script ecosystem: open Lua API, community authors keep writing hero scripts (true since the 2019 forum, now claiming 500+ scripts), making the cheat stronger with use and keeping users on the platform.
  • Free trial + free days/discounts + promo codes lower the barrier to a first try.
  • Referral codes (referrer parameter) and resale on third-party game trading platforms (FunPay refers 1.3%).
  • Community: VK (refers 1.3%), Telegram, Discord 32K, YouTube demo videos.

Speculation:

  • Cheat products can't run mainstream ads, so they rely mainly on player word of mouth and YouTube/VK demo videos to drive "umbrella dota" brand searches.
