Basics

  • Product: automatic-delivery game account store. Games include CS2 (Prime Ready etc.), Rust, R6, Apex, ARC Raiders, Tarkov, DayZ, Battlefield 6, Wardogs, ARK. A JWT login token is delivered immediately after ordering; up to 3 replacements within 6 hours (replaceable if login fails; VAC bans and cooldowns are not covered).
  • Price: CS2 €0.30–2.36, Rust €0.81–1.85, etc. (from the profile file); API examples: Prime Ready €0.45, Rust 1000+ hours €1.85.
  • Payment: bank cards, cryptocurrency (BTC icon on site), on-site balance.
  • Wholesale/resale: public product catalog and stock API; resellers deduct from their balance with an API key, 1–100 accounts per order, with a /reseller page.
  • Companion tool: GitHub fakearchie/nfatool, "nfa.pub Loader", a Windows program that logs into Steam directly with a token and buys or swaps accounts in one click; repo created 2026-05-25, 8 stars. The tria.ge sandbox has a scan record for "nfa-pub-loader setup.exe" (2026-09-28).
  • Operator: nickname archie (GitHub fakearchie, registered 2025-02; Discord invite code archievable); real identity and location not found.
  • Community: Discord (ticket-based support), Telegram t.me/nfapub (81 subscribers, post views about 80–270).
  • Our data/Similarweb data (2026-09): Poland 28.0%, US 22.4%, Azerbaijan 15.2%, Brazil 11.2%, Turkey 9.8%; direct 88.8%, search 8.4% (brand keywords 97%), social 1.7% (YouTube, Discord); +31% month over month, global rank about 310K.

Growth loop

Evidence:

  • Discord is the core: on-site support runs through Discord tickets, the first Telegram post is "the only official channel" and points to Discord; Similarweb social sources are only YouTube and Discord.
  • Wholesale API + loader: opening an API to resellers and tool users turns downstream resale sites and bots into a distribution channel (wholesalers' repeat purchases show up as direct visits).
  • Low prices + instant delivery + replacement guarantee drive high repeat purchases, with direct visits at 89%.

Speculation:

  • "Existing audience": the Discord invite code archievable matches the GitHub name fakearchie, so the operator likely already had a Discord community in the CS2/Rust account or cheating scene and moved existing customers over after the new site launched; no launch post found.
  • YouTube traffic may come from links in the description of CS2/Rust videos about "cheap alt accounts" or "swapping accounts when cheating".
  • The high share of Poland, Azerbaijan and Turkey may be resellers or internet cafe players concentrated in those regions.

Revenue and scale clues

  • No public revenue. Global rank about 310K, estimated monthly visits in the tens of thousands (the Similarweb page shows the number 65,859 without saying what it means); at €0.3–2 per unit, a rough guess of a few hundred orders a day gives monthly turnover of several thousand to over ten thousand euros (pure speculation).

Confidence and gaps

  • New site, written from scratch. Product rules, API, Wayback and GitHub dates are first-hand evidence; the takeoff path (Discord migration) is speculation.
  • Search results are mostly scanner/security sites and unrelated content; the Telegram posts have no dates.
  • Gray-market warning: NFA accounts can be recovered by the original email holder and are often used to evade bans, so platform and payment risks are high.
  • Gaps: operator identity, Discord size, real order volume and revenue.
