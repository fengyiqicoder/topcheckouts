In January 2018, Airbnb engineer Alex Rodionov (a Selenium/Bazel contributor) open-sourced a small macOS tool on GitHub that does just one thing, clipboard history: Maccy, MIT license, free, keyboard-first, native UI. He only built the maccy.app website in August 2019. After that, GitHub stars grew from 181 in 2019-06 to 1,105 in 2020-06 and kept roughly doubling every year up to 22k; from 2020 a $9.99 "sponsor edition" of the same app was sold on the Mac App Store, and Homebrew sees 110k installs a year. Basics

  • Product: macOS clipboard history manager, opened with ⇧⌘C, type to search, Enter to paste; supports ignoring content from password managers, local storage.
  • Pricing: free and open source (GitHub releases, `brew install maccy`); the Mac App Store version is $9.99, described as "This version is being sold on the App Store to support the development" (https://apps.apple.com/us/app/maccy/id1527619437?mt=12; the store seller shows Antonina Ivanova, copyright "© 2017 Alexey Rodionov").
  • Author: Alex Rodionov (GitHub p0deje, based in SF Bay Area, company Airbnb, bio "Alumnium | Bazel | Maccy | Selenium", 891 followers) (https://api.github.com/users/p0deje).
  • Scale: GitHub 22,058 stars, 1,247 forks (2026-10); Homebrew cask installs 8,606 in 30 days, 25,134 in 90 days, 110,988 in 365 days (https://formulae.brew.sh/api/cask/maccy.json).
  • Domain: maccy.app registered 2019-08-06 per RDAP; first Wayback capture 2019-08-22. GitHub repo created 2018-01-31 (v0.1.0 the same day).
  • Traffic profile (profile file): US 15%, India 12%, China 11%; search 68.6% (brand keywords 92%: maccy, maccy for mac, maccy download); referrals apple.com 4.8%; social YouTube, X, Reddit.

Where the first users came from: the evidence points to GitHub open source (58 stars in the first half of 2018, mostly developers) and Homebrew distribution; the specific source of the 6x growth period from 2019-06 to 2020-06 was not found. The testimonials on the website come from the writer Jatan Mehta, the blog The Sweet Bits, the developer @lowercasename and others, which shows some blog/Twitter word of mouth (specific dates not found).

Growth loop

Evidence:

  • Open source + Homebrew: `brew install maccy` gets 110k installs a year, spread by word of mouth in developer circles.
  • "One thing" positioning: both the website and the App Store stress "No fluff", which makes it easy to get recommended in "best clipboard manager / Mac alternative to Ditto" lists (App Store review: "If you used Ditto on Windows, this is the app for you on Mac").
  • App Store traffic: the profile shows apple.com referrals at 4.8%, and the paid version is itself a discovery channel.
  • Word of mouth strong enough to be imitated: fake sites and trojans appeared in 2025–2026.

Speculation:

  • After building the website in the second half of 2019, it may have been recommended once on Hacker News / r/macapps / Product Hunt (a common takeoff path for small open-source Mac tools), but this could not be verified with the tools available, so the launch method is recorded as "Not found".
  • The high share of users from China and India may relate to "must-have Mac apps" lists and videos in Chinese and Indian developer circles (the profile's social sources include YouTube).

Revenue and scale clues

  • Revenue is only the $9.99 sponsor edition on the App Store; no public sales figures. The author has a full-time job at Airbnb, and Maccy is a side project.
  • Scale: 22k GitHub stars and 110k Homebrew installs per year; actual users should be in the hundreds of thousands (speculation, not verified).

Confidence and gaps

  • Written from scratch for a new site. Repo creation, website launch, the yearly star curve, Homebrew install counts and the App Store price all have primary data, so credibility is high.
  • Gaps: the specific channel behind the takeoff event (2019-06 to 2020-06) was not found; the App Store listing date is not verified; Reddit/HN posts did not appear in search results (the reddit/review/tiktok search groups returned nothing).
