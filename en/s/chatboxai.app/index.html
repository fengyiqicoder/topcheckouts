In March 2023, just as the ChatGPT API opened, author Bin Huang (credited as Benn on Product Hunt) open-sourced on GitHub (repo created 2023-03-06) the desktop client he used to tune prompts, catching the "bring-your-own-key ChatGPT desktop app" window. Chinese community posts shared it as "a tool that lets non-programmers use the OpenAI API", English-speaking users found it on GitHub on their own (a Reddit post in 2023-08, "Chatbox changed my life"), and it climbed to 42k stars. After DeepSeek blew up in early 2025, "Ollama/DeepSeek API + Chatbox" became standard in Chinese local-deployment tutorials, and the integration docs of model vendors such as Volcano Engine and Qwen also list it as a recommended client, steadily lifting brand searches and downloads. Basics

  • Product: A cross-platform (Win/Mac/Linux/Web/iOS/Android) AI chat client. You can bring your own API key to connect OpenAI/Claude/Gemini/DeepSeek/Ollama and more, or buy its own model credit subscription, Chatbox AI; supports MCP, a knowledge base and Work Mode.
  • Author: Bin Huang (GitHub Bin-Huang, PH @benn_h), a developer in China; it started as a solo project, and the repo has since moved to the chatboxai organization.
  • Entity: The site's llms-full.txt states the publisher is Mediocre, LLC (a US LLC). No funding found.
  • Open source: Community edition is GPLv3; the site recommends the closed-source "official version".

Growth loop

  • Evidence:
  • Open source + GitHub stars, picked up by various awesome lists, tutorials and third-party reviews; the site's llms-full.txt itself lists "GitHub stars, Product Hunt reviews, third-party tutorials" as sources of word of mouth.
  • Third-party tutorials (especially DeepSeek local deployment) write Chatbox as a must-install step, and readers go straight to the site to download.
  • Model vendors' integration docs send traffic: among referral traffic, volcengine.com is 5.77%, qianwen.com 4.59%, github.com 4.21%.
  • 98.2% of the 26% search share is brand keywords, which means most new users hear about it elsewhere and then search.
  • Speculation:
  • A free BYOK client gets users installed, then the app pushes the "Chatbox AI" model subscription (from Lite $3.99/month) for conversion. Users in China can't buy overseas APIs, so the subscription is a shortcut to "one account for many models", which would explain why checkout visits mainly come from China.
  • It is famous enough to attract knockoff sites (someone on LinkedIn warned about a scam site called "ChatBox" charging $59.99), which indirectly shows the brand keyword has value.

Revenue and scale clues

  • Pricing: BYOK is free; Chatbox AI Lite $3.99/month ($3.50 billed yearly), Pro $19.99/month, Pro+ $39.99/month (https://chatboxai.app/pricing.md).
  • GitHub 42.1k stars (2026-10).
  • MRR and user count: no official public figures found.
  • Our data: last month checkout visits 21,490, six months ago to four months ago averaged 24,530, China 47%.

How did Chatboxai get started?

In March 2023, just as the ChatGPT API opened, author Bin Huang (credited as Benn on Product Hunt) open-sourced on GitHub (repo created 2023-03-06) the desktop client he used to tune prompts, catching the "bring-your-own-key ChatGPT desktop app" window. Chinese community posts shared it as "a tool that lets non-programmers use the OpenAI API", English-speaking users found it on GitHub on their own (a Reddit post in 2023-08, "Chatbox changed my life"), and it climbed to 42k stars. After DeepSeek blew up in early 2025, "Ollama/DeepSeek API + Chatbox" became standard in Chinese local-deployment tutorials, and the integration docs of model vendors such as Volcano Engine and Qwen also list it as a recommended client, steadily lifting brand searches and downloads. Revenue comes from the official version's model subscription (Chatbox AI Lite/Pro).
