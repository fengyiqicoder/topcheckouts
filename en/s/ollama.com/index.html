v0.0.1 was released on 2023-07-08, and ten days later it caught the open-sourcing of Llama 2 (7-18). Two former Kitematic (the Docker GUI, acquired by Docker) founders wrapped llama.cpp into a "Docker-style" one-line command, `ollama run llama2`; the same day Simon Willison blogged a recommendation, and a few days later Replicate's official tutorial included it, so the first users were the readers of these developer opinion leaders. After that, every new open-source model release (Code Llama, Mistral, Llama 3, DeepSeek R1, gpt-oss) became a free traffic pulse: Ollama listed it the same day, and tutorial authors default to writing `ollama run xxx`. An official Docker image, an OpenAI-compatible API, Python/JS libraries and integrations like Firebase Genkit turned it into the default base for local LLMs (67K+ integrations); Cloud models launched in 2025-09, in 2026 it hooked into coding agents like Claude Code/Codex/OpenClaw, and it monetizes with the Pro $20/month subscription.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: an open-source local LLM runner (CLI + local API + a desktop app since 2025-07), plus an Ollama Cloud subscription for cloud models (Free / Pro $20/month or $200/year / Max $100/month / Team).
  • Team: Jeffrey Morgan (CEO) and Michael Chiang, who previously built Kitematic (acquired by Docker in 2015). The company is in Palo Alto, USA.
  • Funding: YC W21 (amount varies by aggregator, about $125K); on 2026-07-09 a $65M Series B led by Theory Ventures (with Benchmark, 8VC, YC and others), $88M total.
  • First release: GitHub v0.0.1, 2023-07-08 (https://github.com/ollama/ollama/releases/tag/v0.0.1, cited by Wikipedia).
  • Domain WHOIS registered 2017-05-08 (long before the product, possibly an old domain that was bought).

Growth loop

  • Evidence:
  • First users: Simon Willison's blog post (2023-07-18) + Replicate's official tutorial (07-22), both in the same week as the Llama 2 release, with readers who are developers on Macs.
  • Open source + integration ecosystem: the official Docker image, OpenAI-compatible API, Python/JS libraries, Firebase Genkit, Obsidian and IDE plugins; 67K+ third-party integrations treat Ollama as the default local backend, and users installing other tools are told to install Ollama first.
  • Launch-day model listings: in the official blog, nearly every major model release (Code Llama, Llama 3, Gemma 2, gpt-oss, Qwen3-VL, MiniMax M2…) has a same-day listing post.
  • The Agent wave: in early 2026 it hooked into Claude Code, Codex and OpenClaw, taking users from "local chat" to "running coding agents locally/in the cloud".
  • Speculation:
  • A new model release = a traffic pulse: tutorial and video authors produce `ollama run xxx` content on their own, and searches for "deploy XX locally" land on ollama.com.
  • Paid conversion: big models that cannot run locally are steered to the Cloud subscription, the CLI habit does not change, and free users convert straight to paid.

Revenue and scale clues

  • Nearly 9 million users / 8.9 million developers, 67K+ integrations (2026-07).
  • Pricing: Free $0 / Pro $20/month ($200/year) / Max $100/month / Team. https://ollama.com/cloud
  • No public MRR/ARR found.
  • Our data: last month checkout page visits 73,066 versus an 4–6 months ago average of 104K, a slight decline; top country China.

Confidence and gaps

  • Founders, funding, the first release date (v0.0.1) and the blog timeline are credible.
  • The Show HN original post is still not located; the idea that China traffic comes from the DeepSeek deployment wave is Speculation.
