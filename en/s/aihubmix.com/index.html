In late 2023 the ChatGPT API was hard to buy directly from inside China (you needed a foreign credit card, had to apply for a key, and had to get past the firewall), so AIHubMix built an "OpenAI API relay/aggregation site": Alipay top-ups, direct access from China, OpenAI-compatible format, one key to call GPT, Claude, Gemini and domestic models. The key move was burrowing into open-source AI clients and developer tools: it gives developers an "APP-Code" where any open-source project that names AIHubMix as its model provider in its docs or UI gets 10% off on calls routed through that project, plus invite links carrying aff referral codes. As a result Cherry Studio (50K stars) listed it as a built-in provider from 2024-07, AstrBot (40K stars) put a referral-code link in its README, and Claude Code, Codex, cc-switch and other tools all have integration docs for it. Every developer using these tools sees it in the provider list. Since then it has kept things fresh by racing to add new models first, offering free models and running limited-time discounts, and translated its docs into multiple languages to go international.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: AI model API aggregation gateway, 710+ models (text, image, video, audio), compatible with the OpenAI / Anthropic / Gemini protocols; usage-based billing, no membership; free models (officially 27+ to 64), enterprise self-hosted edition, status page, invoicing system, Vercel AI SDK provider.
  • Claimed advantages: official authorized partner of Azure, AWS and GCP; servers and database on Azure in the US; accepts Alipay and Stripe (GitHub README).
  • Team: operating entity and founders not found; early GitHub repo account akakenle (created 2023-12-17), aimed at Chinese developers (the first version of the site had only a Chinese description, "large-model reseller"). Backup domain api.inferera.com.
  • Domain: registered 2023-12-03 (RDAP), first Wayback capture 2023-12-16.

Growth loop

Evidence:

  • Embedded in open-source clients: built into Cherry Studio (since 2024-07), referral-code link in the AstrBot README, integration docs for all sorts of AI coding tools.
  • Kickbacks for developers: APP-Code trades 10% off for attribution; aff referral codes.
  • Search capture: our data shows non-brand keywords such as "cc switch" and "ox alpha" (developer tool names; new users from SEO about 21%), meaning its docs pages catch users who are searching for tool setup guides.
  • Directories and benchmark sites: toolify.ai refers 2.7%, listed on speed-test sites such as LMSpeed; Feishu (feishu.cn) refers 3%, probably setup notes in Chinese teams' internal docs.
  • Free models as the entry point: free models can be called right after signing up.

Speculation:

  • The first users were Chinese developers who couldn't get the OpenAI API in late 2023 and found it via word of mouth on GitHub, V2EX, Zhihu and open-source project READMEs (no specific posts seen).
  • After Agent coding tools like Claude Code took off in 2025, demand for "how to use Claude Code from China" drove a second wave; the cc-switch keyword points to this.
  • US 11.8% and India 10.9% traffic suggest multilingual docs and "free models" are starting to attract overseas developers.

Revenue and scale clues

  • Usage-based billing; example model prices: Claude Opus 5.5 $4/$20 per million tokens, GPT 6.1 Sol $2/$10, some at a limited-time 30% off.
  • Our data: China 26.4%, United States 11.8%, India 10.9%; direct visits 52.4% (returning users top up and make calls directly in the console).
  • Revenue and user counts not found.

Confidence and gaps

  • Launch date, Cherry Studio integration date, the APP-Code mechanism and open-source referral links have first-hand evidence (GitHub, official docs).
  • Search results are mostly irrelevant AI tool rankings; no founder interviews or launch posts found.
  • Gaps: operating company and founders, which community the first users came from, revenue scale, aff referral commission rate.
