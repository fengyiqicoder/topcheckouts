AIGoCode (operated by ZIMACODE LLC) registered in 2025-08 and launched in September as a relay: "one key for Claude/Codex/Gemini, direct access from China, RMB subscriptions". Its biggest acquisition move came in 2025-12: sponsoring CC Switch, a 140k-star open-source Claude Code configuration switcher on GitHub, with an exclusive invite link in its README (10% bonus on first top-up). Basics

  • Product: Chinese-language AI coding relay/workbench. A unified API key for Claude, GPT/Codex, Gemini, Grok, GLM, Kimi; quota and usage management, team member and key management, desktop client, OpenClaw integration docs; enterprise edition supports contracts and invoices.
  • Who built it: team.aigocode.com footer says "Operated by ZIMACODE LLC" (search summary); founder not found (not the focus). Also owns aigocode.net (the domain used for the CC Switch invite link) and aigocode.app (registered 2026-06-05).
  • Launch date: RDAP registration 2025-08-29; first Wayback capture 2025-09-19.
  • Pricing (profile): pay-as-you-go prepaid; Pro ¥399/4 weeks ($440 quota), Max ¥899/4 weeks ($1,040), Ultra ¥1,799/4 weeks ($2,120); subscriptions save up to 15% vs pay-as-you-go; quota refreshes every 7 days.
  • Self-reported on site: 10,000+ developer users, 5M+ tasks, 99.9% uptime, 1-on-1 support.
  • Traffic (profile): US 56%, Hong Kong 18%, China 15% (most likely proxy/VPN exit nodes); direct 80.6%, referrals 14.5% (github.com 4.1%); brand keywords 80.6%; social only X 2.9%; has a Telegram user group (site link t.me/+DjOEPVxszZw2NjRh).

Where the first users came from: no direct evidence for the first two months (2025-09 to 11); presumably word of mouth and invite codes in Chinese developer circles (X, Telegram, WeChat groups) (speculation). The evidenced scale-up point is the 2025-12 CC Switch sponsorship: that open-source tool exists precisely for people "running Claude Code through third-party relays", so the README sponsor slot hits the target user exactly, and it is the source of the 4.1% github.com referrals in the profile.

Growth loop

Evidence:

  • Invite rebates: every user has an /invite/ code; Wayback captured dozens of distinct codes, meaning users post invite links everywhere.
  • Open-source sponsorship: exclusive invite code in the CC Switch README + 10% first top-up bonus.
  • Bootcamp/community partnerships giving away quota (Peng Tao's bootcamp).
  • Subscriptions renew every 4 weeks + quota refreshes every 7 days, so returning users visit directly and often (direct 80.6%).

Speculation:

  • Competition among relays runs mainly on a "stable + no bans" reputation spread in Chinese developer Telegram/WeChat groups; Claude Code's restrictions on China (a 2026-07 article on "China-specific telemetry") only increased demand for relays.

Revenue and scale clues

  • Site self-reports 10,000+ developer users; plans ¥399–1,799 / 4 weeks. If 10% of users subscribe to Pro, monthly revenue would be about ¥400k (pure speculation).
  • US + Hong Kong account for 74% of traffic, meaning most users are overseas or on proxies.

Confidence and gaps

  • New site, written from scratch. Search results were mostly irrelevant (the first set was all "health"); main evidence from the CC Switch repo README and commit history (GitHub API), invite links in Wayback CDX, the site homepage, RDAP and Peng Tao's blog.
  • Founder, ZIMACODE LLC's registration location and real revenue not found; user count is self-reported.
