Basics

  • Product: an open-source AI prompt community (formerly Awesome ChatGPT Prompts) to share, discover and save prompts, skills and workflows; Next.js + Prisma + PostgreSQL, self-hostable with Docker; offers a CLI (npx prompts.chat), an MCP service (prompts.chat/api/mcp), a Claude Code plugin, a Chrome extension, prompts.csv data export, a free interactive tutorial "The Interactive Book of Prompting" (29+ chapters) and a prompting game for kids. Prompt content is CC0, code is MIT. https://github.com/f/prompts.chat
  • Author: Fatih Kadir Akın, Istanbul, "Head of Agentic Experience" at Automattic (parent of WordPress), 11,651 GitHub followers, GitHub Star. https://github.com/f
  • Monetization: free; sponsors Neon, Clemta, Wiro, Cognition (Windsurf), CodeRabbit, Sentry, Each Labs, CommandCode; a book on Gumroad (art-of-chatgpt-prompting).
  • Scale: GitHub 174.4K stars, 22.3K forks, 9,788 commits (2026-10).
  • Traffic mix (profile record): direct 63.4%, referral 27.5% (mainly the GitHub project page, plus gitcode.com, zhihu.com, insanelyusefulwebsites.com), brand keywords 68.8%, non-brand search 0; United States 16%, India 11%, China 9%.

Growth loop

Evidence:

  • Catching the window: it opened the repository 5 days after ChatGPT launched and the web version in 10 days, becoming the "first prompt library", shared by major media and industry leaders as a standard reference.
  • Community contribution: every prompt credits the contributor's GitHub ID, so contributors who submit PRs have a reason to share it; the repository has 9,788 commits and 22K forks to date.
  • Multi-endpoint distribution: Hugging Face dataset, CSV export, CLI, MCP, Claude Code plugin and Chrome extension put the prompts into other people's toolchains, sending traffic back to the main site.
  • GitHub itself is the largest traffic source (referral 27.5%, mainly the GitHub project page).

Speculation:

  • The "awesome list" format naturally makes GitHub Trending, and the early star surge likely came from Trending and X/Twitter shares (from memory, unverified: the repository hit #1 on GitHub Trending several times between 2022-12 and 2023-01).
  • Chinese developers arrive through the gitcode mirror and Zhihu articles, making up 9% of visitors.

Revenue and scale clues

  • No direct revenue figures; 8 corporate sponsors (Neon, Sentry, CodeRabbit, Cognition, etc.), the open-source sponsorship model.
  • Scale: 174.4K stars, 22.3K forks; the profile record shows direct visits at 63%, indicating many returning users.

Confidence and gaps

  • The GitHub stargazers timestamp API needs authentication, so the star growth curve was not obtained, and which HN/X post caused the early surge was not found.
  • The original Forbes article was not opened; only the date cited in the README is used.
  • The Reddit r/PromptEngineering post would not open (summary only).
  • This is a new site, written from scratch this time; the evidence comes from the GitHub API, the README, RDAP/Wayback, the dev.to article and search snippets.
