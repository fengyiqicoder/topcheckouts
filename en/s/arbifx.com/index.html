Basics

  • Product: AI VFX engine that generates filters, particles, models and scenes from natural language, with real-time adjustable parameters, support for visual references and interaction with cameras and layers; Windows x64 installer v2.1.1 (macOS coming soon), also used as an After Effects plugin (GitHub README: "download the ArbiFX plugin… install it in After Effects"); requires login to create an API Key.
  • Pricing: credit packs $2.90 (1,500) / $12 (7,500); subscriptions Starter $9.90 / Pro $19.90 / Max $39.90 per month (profile). New users get 1,200 free credits (Bilibili description).
  • Team: started as a personal project (Bilibili description: "a personal project I have kept developing for nearly half a year"), footer "ArbiFX Inc.", contact email oxoxxidane@gmail.com; Bilibili UID 151341332, 7,018 followers, 40 uploads; GitHub Oxoxxidane (registered in 2019).
  • Domain: registered 2026-04-16 (RDAP; the 2018/2021 Wayback records belong to a previous domain holder).
  • Traffic (profile): referrals 95.5%, no country or search term data; language mainly Chinese.

Growth loop

Evidence:

  • Bilibili launch video + free credits → download and trial.
  • Community gallery: user-generated effects are shown publicly and can be commented on (effects pages) → new users see finished results → download.
  • Plugs into the AI agent ecosystem (Code2AE skill) to ride the popularity of tools like Claude Code/Codex.

Speculation:

  • The 95.5% referral traffic may come from the link in the Bilibili video description and the desktop client / login callbacks rather than external websites.
  • AE creators using ArbiFX-generated effects in their work could bring secondary spread if they share tutorials or project files (no evidence seen).

Revenue and scale clues

  • No user count or revenue data. The launch video's 25K views is the only visible scale indicator; the author has 7K followers, an early-stage product.

Confidence and gaps

  • The site is written from scratch. The launch date, video data and author identity are backed by raw Bilibili API and GitHub API data, so credibility is high.
  • Gaps: whether the author has posted more promotional videos since (the full upload list was not pulled); whether it is spreading on Xiaohongshu/Douyin/X; paid conversion.
