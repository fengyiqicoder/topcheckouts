Lunor started as a Roblox cheat script (best known for its script for the fishing game Fisch). It built the Discord "Lunor Lounge" in April 2025 and grew it to 65,000 members. In January 2026 it first posted its terms on GitHub Pages, and in February registered lunor.wtf, expanding its own script store into a multi-seller reseller shop for "Roblox executors / scripts / external tools" (Potassium, NinjaKernel, Chiyo, Harvard Labs and others; NinjaKernel's official site lists it as the only authorized reseller). Traffic is almost all direct visits from people clicking links in Discord communities (86.7%), and affiliate commissions (paid weekly via PayPal/crypto) get script authors and big Discords (Speed Hub X, 370,000 members) to send traffic its way.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: a license key store for Roblox executors, scripts and external macro tools; keys delivered on payment, lifetime or 30-day; has product showcase pages, a blog (e.g. 2026-10-04 "Script Keys vs Executor Keys") and a Feedback page. Prices: Lunor script lifetime $10 / 30 days $5, Chiyo $20, Solix $15, Harvard Labs $5, Potassium $22.99, NinjaKernel $15 and so on (profile data + product pages).
  • Who built it: an anonymous team; the terms say only "Lunor.wtf and its operators"; the terms and privacy pages were first hosted on GitHub Pages of the user writeprocessmem (account registered 2025-05-26, the only repository "lunor" created 2026-01-21).
  • Community: Discord invite discord.gg/LNR leads to the server "Lunor Lounge", about 65,275 members, 4,946 online; the server ID converts to a creation time of 2025-04-22. The homepage testimonial comes from the Speed Hub X owner AV999 ("Owner of Speed Hub X • 310K+ Members"), and the homepage also links discord.gg/speedhubx (Speed Hub X's official server has about 370,000 members and was likewise created 2025-04-22).
  • Affiliate program: /affiliate "Partner with lunor.wtf… earn recurring commissions… Weekly Payouts via PayPal or Crypto", log in with Discord to get a personal link and a stats dashboard.
  • Launch date: terms "Last updated: January 21, 2026";.wtf RDAP registered 2026-02-03 (Namecheap); first Wayback snapshot 2026-08-01.
  • Traffic (profile data): US 98.3%; direct 86.7%, social 9.9%, search 2.0% (brand keywords 88.7%).

Where the first users came from: the users of the Lunor script's own Discord (evidence: the store homepage sends traffic to discord.gg/LNR with 65,000 members; the script itself is called Lunor, and the store grew out of selling the script's keys). The store's first buyers were the players who had been buying Lunor script keys (speculation, but consistent with the timeline: Discord 2025-04 -> store 2026-01/02).

Growth loop

Evidence:

  • Discord community -> store: direct visits are 86.7%, and the homepage pushes Discord.
  • Affiliate commissions: log in with Discord to get a link, settled weekly.
  • Multi-seller reselling: executor/script authors list lunor.wtf as an authorized reseller (NinjaKernel), which means the authors send their own users here.
  • Endorsement from a large community: recommended by the Speed Hub X owner.

Speculation:

  • The loop is "more scripts/executors listed -> each author's Discord sends users -> sales and commissions -> attracts more authors". Each time Roblox updates and blocks executors (such as Hyperion/Byfron), players have to buy new keys again and again, so repeat purchases are high.
  • Users are mostly US teenagers, so payment and refund dispute risk is high; search and SEO barely matter.

Revenue and scale clues

  • The homepage has "Sales and counting / Customers / Average rating" counters (JS-rendered, numbers not captured); the affiliate page has "Total Paid Out $X.XK+" (likewise not captured). Discord has 65,000 members. Average order $5-23. Monthly gross sales are presumably in the tens of thousands of dollars (speculation, unverified).

Confidence and gaps

  • Written from scratch for a new site. Search results were mostly irrelevant (Lunar Client, adult sites); the only relevant Reddit posts are generic executor discussions from 2023. Evidence mainly comes from the official site, the Discord invite API, the GitHub API, NinjaKernel's reseller page and RDAP.
  • The operators' identity, real sales and the affiliate commission rate (the page shows "0%", which is a JS placeholder) were not found.
