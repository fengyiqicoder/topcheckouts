Basics

  • Product: free open-source desktop software Arnis (Rust, Apache 2.0); draw a box on the map to generate a Minecraft Java/Bedrock/Luanti world. Paid online version MapSmith generates in the browser, works on phones, up to 500 km².
  • Founder: Louis Erbkamm (GitHub louis-e), maintained solo in his spare time (site says he "works on Arnis in his spare time"). Has Discord, Instagram @arnisworlds and Buy Me a Coffee tips.
  • Pricing: desktop free; MapSmith pay-per-generation from €3 (≤0.2 km²) to €50 (500 km²), middle tiers €5/€10/€15/€25 (compiled from competitor map2minecraft's comparison page, https://map2minecraft.com/compare).
  • Launch date: GitHub repo created 2022-09-10; v1.0.0 release 2024-08-16; arnismc.com registered 2025-09-13 (RDAP), earliest Wayback snapshot 2025-12-16; README names arnismc.com the "only official website" from 2025-10-24.
  • Traffic (profile): US 17%, Germany 12%, France 7%; search 63% but 90% brand keywords, direct 28%, social from YouTube, X, Facebook.

Growth loop

Evidence:

  • Launch and takeoff on GitHub + Hacker News: within a week of the 2024-12 GUI release it hit the HN front page, followed immediately by tech press (Hackaday, XDA, Tom's Hardware); the author confirms in the README that it "gained more attention in 2024-12".
  • Branded output: user-generated city worlds are inherently shareable content; YouTube tutorials/showcases and CurseForge world saves all carry the "Arnis" name, and viewers then search the brand. The profile shows 90% of search is brand keywords.
  • The wave of copycat sites (issue #224) is indirect proof of large brand search volume, which is why the author registered an official site as the single entry point.

Speculation:

  • The first 1,000 users most likely came from GitHub trending / HN / Reddit Minecraft and OSM communities (OSM Wiki has a dedicated page); the original Reddit launch post was not found.
  • MapSmith monetization relies on the site + README steering free users who "want bigger maps or phone use" to the paid version; conversion rate unknown.

Revenue and scale clues

  • GitHub 18.4k stars; cumulative release downloads about 939k (GitHub direct links only, excluding site distribution).
  • MapSmith €3–€50 per order, no public revenue data; run solo in spare time, with Buy Me a Coffee and GitHub Sponsors on the side.

Confidence and gaps

  • Takeoff timing and source (2024-12 HN + press) are well evidenced, from the GitHub API, HN API and README text.
  • Gaps: no author interview or Reddit launch post found; MapSmith's exact launch date not found (Wayback was rate-limited this round), only inferred as "2026-03 at the latest" from the paid-complaint issue; no revenue data.
  • Search results were mostly irrelevant ("launch"/"review" queries returned SQL tools, ointments, etc.); evidence relied mainly on GitHub/HN/RDAP.
