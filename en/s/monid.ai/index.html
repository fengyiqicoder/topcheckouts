Basics

  • Product: monid.discover() (ranks candidate tools by fit and price) + monid.run() (calls them without signing up to each one), integrated via SKILL.md, a remote MCP server or CLI; charged per call from a unified balance (about $0.0013 per call + a 10% platform fee, no charge for failures), new users get $1; there is an affiliate program; third parties can list tools. The core engine is MIT open source (Deno 2 + TypeScript).
  • Company: Monid Inc, a Delaware C-Corp, San Francisco. CEO Shengkun Ye; Head of Growth Zongrong (Jasper) Li; members Feiyou Guo and Zuoyou (Octo) Dang.
  • Funding: pre-seed $2.1M in 2026-09; seed $7.7M on 2026-10-06 (led by Long Journey Ventures, with Madrona, Essence VC, Pioneer Fund and 1984 Ventures participating), $9.8M in total (Yahoo Finance).
  • Community: X @monidhq, Discord, GitHub monid-ai (main repo 6.4k stars, created 2026-08-26), awesome-monid (72 community projects), the Agent Hunt leaderboard monid.ai/rankings (2.5K followers on PH).

Growth loop

  • Evidence:
  • First users: the PH launch (04-23) + a 2.0 relaunch two weeks later (05-08), showing the first 1,000 users came mainly from the AI developer circles on PH and X; there is a dedicated Head of Growth.
  • Takeoff event: open source at the end of August + the hackathon on September 1 + #1 of the day on PH on September 2, a three-in-one launch; August checkout visits were 4.6x the April–June average.
  • The hackathon uses Monid credits as prizes → participants must sign up and top up to use it → their projects go into the awesome-monid list and become case studies for the next batch of users.
  • Agent Hunt leaderboard: it ranks tools using the platform's transaction data, so tool vendors have an incentive to repost their own rankings (supply side brings traffic), and it also gave PH a reason to launch again.
  • Channel profile: direct 47.5%, social 39.3% (mainly X), search 7.9%, referrals include directory sites such as agent-finder.co.
  • Speculation: developers write the Monid Skill into open-source Agents/templates, and others who clone them need a Monid key to run them (dependency-style spread); the funding news (October) brings another wave of media traffic.

Revenue and scale clues

  • Self-reported 4M+ Agent calls (2026-10); at $0.0013 per call, tool volume would be only a few thousand dollars, but many paid tools have higher unit prices, plus a 10% platform fee, and actual revenue is not disclosed.
  • August–September checkout visits were about 17–18K per month (mostly balance top-ups). Total funding $9.8M.

Confidence and gaps

  • Medium-high. PH launch records, the hackathon and the funding all have page evidence; user counts and revenue are not disclosed, and there is no first-hand account of what the first 1,000 users consisted of (PH or X posts).
  • Second follow-up check: changed the takeoff method from "New-platform window" to "Launch platform" (found 4 PH launches, with the first launch on 04-23 being the go-live month); added CEO Shengkun Ye, the $2.1M pre-seed + $7.7M seed, the September hackathon, the Agent Hunt leaderboard and the self-reported 4M calls.
