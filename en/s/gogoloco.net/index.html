Basics

  • Product: VRChat avatar locomotion prefab. Go All (sit/lie/poses/expressions/AFK/play space, uses 16 parameter bits) and Go Beyond (adds flying and dashing, 17 bits); supports PC, Quest (Android) and iOS. Companion products GoGo Freeze and GoGo Fly.
  • Price: free. Gumroad pay-what-you-want from $0 (page data has a $6.99 price field, presumably a suggested tip), Booth free download + a 450 yen "Support Me!" tip version.
  • Team: creator Franada (GitHub registered 2018-12, bio "I do thing for the game VRChat"; X @franadaVRC); the site lists moderator Prism and moderator/web developer RootVR.
  • Community: Discord server, VRChat Group (GGL.8930).
  • Domain: gogoloco.net registered 2023-02-01 (RDAP; Wayback records from 2010–2014 belong to a previous owner); archived continuously since 2023-07; sitemap lastmod 2026-06-27 (site redesign).
  • Traffic (profile): 4,918 visits in 2026-09, stable at 4–6k/month long term; US 47.7%, Russia 8.0%, Mexico 7.5%; search 74.1%, brand keywords 93.5% (gogoloco, gogoloco vcc, gogoloco download).

Where the first users came from: the VRChat player and avatar-creator community itself, via free releases on Booth (the Japanese avatar marketplace where most VRChat avatars are traded) and Gumroad, plus YouTube install tutorials and Discord. The real amplifier is the license allowing it to be bundled into commercial avatars: avatar authors preinstall it or list it as a dependency, and buyers follow the instructions to search "gogoloco".

Growth loop

Evidence:

  • License requires commercial avatars that bundle it to keep the GoGo Loco menu icon → every avatar buyer sees the brand → others in VRChat see an avatar "sitting in mid-air / lying down" and ask how → search gogoloco to download (brand keywords 93.5%).
  • Third-party avatar products list GoGo Loco as an install dependency (Ko-fi, Jinxxy product pages), creating creator-supply-side distribution.
  • Integration with VRCFury, Modular Avatar and VCC auto-install lowers the barrier to use.

Speculation:

  • YouTube tutorials (official and third-party) are the main first-touch channel for new players (view counts not obtained).
  • The free + tips model removes any paid barrier competitors might have, making it the default standard.

Revenue and scale clues

  • Mostly free; income is only Gumroad/Booth tips, presumably very small (speculation).
  • Scale indicators: Gumroad 447 ratings at 5.0; GitHub 26k downloads for a single version and 34k cumulative for the legacy repo (most users go through Booth/Gumroad/VCC, so actual installs should be far higher); site traffic 4–6k/month.

Confidence and gaps

  • New site, written from scratch. Start date (site says early 2021), Booth listing date (search snippet), GitHub versions and download counts (API) and Gumroad rating (page JSON) are fairly credible.
  • The 2022 takeoff year is inferred: GitHub opened 2022-05 and it was a common community component by 2023; no specific breakout event was found.
  • Gaps: Booth wishlist count, total Gumroad downloads, YouTube tutorial view counts, Franada's real identity.
