Basics

  • Product: a PaaS that deploys apps from Lovable, Cursor, Bolt, v0 or a GitHub repo into an isolated cloud workspace; supports ZIP upload/Git connection in the browser, a CLI (npm package @vibedhost/cli) and an MCP for Claude Code / Cursor / ChatGPT; also one-click apps such as WordPress, n8n, PocketBase, Ghost and Umami, plus one-click databases (site https://www.vibedhost.com/).
  • Pricing: subscription, six monthly tiers at €7.99 / €14.99 / €26.99 / €49.99 / €89.99 / €159.99, scaled by vCPU/memory/bandwidth, no free tier.
  • Who built it: neither the site nor the terms of service name a company entity or address, only an email; the npm package maintainer is vibedhost@gmail.com, author name "VibedHost Cloud Engine." In a search summary, X user Youness KASMI (@kasmiyouness1) posted "This is exactly why I built VibedHost.com" (summary only; the X page could not be opened). Combined with traffic 100% from Morocco, presumably a Moroccan solo developer (Speculation).
  • Launch date: domain registered 2026-07-13 (RDAP); first npm CLI release 2026-09-02, iterated to 1.1.9 by 09-23; terms of service "Last updated: last month"; no Wayback captures. Overall judgment: launched last month.
  • Traffic (profile): direct 42.4%, search 43.2% (brand keywords 85.6%: vibedhost, vibed host), referrals 8.6%; country Morocco 100%, very small sample.

Growth loop

Evidence:

  • The founder rides the "vibe coding deployment/billing" topic on X to draw traffic (summary only).
  • Hooks into Claude Code and Cursor via the CLI and MCP, aiming to embed itself in the AI coding workflow (site, npm).

Speculation:

  • No growth loop has formed yet. The product carries no outward branding (whether deployed sites use a vibedhost subdomain unverified), there is no free tier, no referral commission, the blog is empty, and search ranking has not started.
  • If it does take off, the most likely path is posts in vibe-coding circles on X/Reddit or listings in MCP directories.

Revenue and scale clues

  • No public revenue. Lowest tier €7.99/month, traffic small and concentrated in Morocco; the CLI's 446 monthly downloads are the only usage signal. Paying users presumably in the single digits to a few dozen (Speculation).

Confidence and gaps
