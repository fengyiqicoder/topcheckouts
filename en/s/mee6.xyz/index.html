Discord launched only in 2015, and in early 2016 its bot ecosystem was almost empty. French developer Anis (GitHub name cookkkie) built MEE6 in March 2016: a web dashboard where a few clicks add custom commands, levels and welcome messages to a server, with no programming needed. The code was open-sourced on GitHub and listed on early bot rankings such as Carbonitex. Once an admin of one server installed it, every member saw named messages like "MEE6 congratulates you on reaching level X" every day, and admins of other servers then searched "mee6" to install it: the bot itself was the ad space. Once its install base made it the default choice in the Discord ecosystem, features were gradually moved into a per-server Premium.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: the Discord server bot MEE6: moderation/auto-moderation, levels and leaderboards, custom commands, welcome messages, reaction roles, Twitch/YouTube/Reddit notifications, tickets and more; MEE6 AI added later (profile file, competitor blog).
  • Pricing (2026-08, per server): Premium $11.99/month, $49.99/year, $89.99 lifetime; MEE6 AI is charged separately (individuals $41.88-$119.88/year, servers from $3.49/month); social notifications, more custom commands and others are behind the paywall (vibebot competitor blog).
  • Who built it: the bot's registered owner is anis#0 (bots.ondiscord.xyz), the GitHub repo author is cookkkie; the company is in France (from memory, not verified).
  • Launch: RDAP registration 2016-02-15; the bot account ID 159985870458322944 converts via the Discord Snowflake ID to a creation date of 2016-03-17; the earliest Wayback, 2016-03-22, shows the homepage "Mee6: the Discord bot!... Release your!power,!mana,!chakra,!skill for everyone in your server - Add to discord", with GitHub and Discord community links in the nav.
  • Current traffic (profile file): United States 33.3%, Germany 9.3%, United Kingdom 7.6%; direct 75.6%, brand keywords 97.5% of search; referrals twitch.tv and linktr.ee; social Discord, YouTube, X.

Where the first users came from: the circle of early Discord developers/admins. The evidence: the 2016-03 homepage links straight to GitHub and the Discord support server, and the code is open source; the repo contains a Carbonitex reporting component, which suggests it was listed on the only bot ranking at the time and found by admins (speculation based on the component name). The specific first server list and count were not found.

Growth loop

Evidence:

  • Install once, visible to the whole server: level, welcome and notification messages are all sent in the server under the MEE6 name, and members who see them search the brand term (profile file: direct 75.6%, brand keywords 97.5%, "new-user source: viral").
  • Web dashboard configuration lowers the barrier: "add commands without programming" (GitHub README).
  • Streamers/communities use the Twitch and YouTube notification features, and twitch.tv and linktr.ee send referrals (profile file).

Speculation:

  • In 2016 Discord was in its boom phase with very few bots, so MEE6, which got in first, became the default install for new servers, and tutorial videos and "must-have bots" lists amplified it.
  • Moving features behind the paywall later caused resentment, and competitors (Carl-bot, Dyno, etc.) pulled away some users with "MEE6 alternatives".

Revenue and scale clues

  • Premium is charged per server: $11.99/month, $49.99/year, $89.99 lifetime; there is also a MEE6 AI subscription.
  • bots.ondiscord.xyz alone shows 840K invites; the site claims "millions of Discord servers" (search summary), with no primary numbers.
  • Revenue figures not found.

Confidence and gaps

  • New site, written from scratch. Search results were mostly help-center pages and generic rankings; Wikipedia has no MEE6 entry. The evidence comes from Wayback (the 2016 site, archived GitHub repo pages), the bot's Snowflake ID calculation, bots.ondiscord.xyz, RDAP and the profile file.
  • The founder's full name, the corporate entity, the server count growth curve, when Premium launched and the 2022 NFT avatar controversy (from memory, not verified, not put in the timeline) were not confirmed.
