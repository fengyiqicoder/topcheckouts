Soundflower, the free virtual audio driver everyone used on Mac, stopped being updated and could no longer be installed on newer macOS versions, leaving a gap. In September 2019 Existential Audio put BlackHole on GitHub as an open-source replacement. When the pandemic hit in 2020, huge numbers of people needed to share computer audio in Zoom, record system sound in OBS, and run online rehearsals and podcasts, and on HN, forums and tutorial blogs people kept recommending "use BlackHole instead of Soundflower". It then became installable with one Homebrew line and the default dependency in tutorials for recording and AI meeting-notes tools, and its name turned into a search term (blackhole 2ch). It makes money from the $10 donation on the download page, GitHub Sponsors, commercial licenses (you buy a license outside the GPL) and sponsors, and uses the traffic to promote its own paid apps Dipper and Flash Metro.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: BlackHole (macOS virtual audio loopback driver, 2/16/64/128/256 channels, zero latency, GPL-3.0); Dipper (Mac audio recording/capture); Flash Metro (metronome, on the Mac App Store).
  • Team: GitHub organization ExistentialAudio, located in Burnaby, BC, Canada; licensing contact devinroth@existential.audio, i.e. Devin Roth (individual developer, background not verified).
  • Scale: BlackHole has about 20K stars and 852 forks on GitHub (2026-10).
  • Domain: existential.audio registered 2017-05-21, first Wayback capture 2018-08-12; GitHub organization created 2019-09-10, BlackHole repository created 2019-09-27.

Growth loop

Evidence:

  • Replacement tailwind: after Soundflower stopped being updated, HN and other communities repeatedly recommended BlackHole as the replacement, concentrated in the 2020 pandemic.
  • Search ranking: our channel data shows search at 51.3%, with keywords "blackhole", "blackhole audio", "blackhole 2ch", "blackhole mac"; the brand name is itself the category term.
  • Tutorial ecosystem: referrals come from tutorial blogs such as tistory in Korea and note in Japan; the README ships its own routing tutorials for Logic, GarageBand, Zoom and FaceTime.
  • Depended on by other products: Show HN projects (such as Pluely) list BlackHole as the macOS system-audio solution; commercial products either open-source themselves or buy a license, treating it as a default dependency.

Speculation:

  • After AI meeting-recording and transcription tools (Recall.ai type) took off, many tool docs tell users to install BlackHole first, creating a second wave of demand.
  • One-line Homebrew install spreads it by word of mouth among developers.

Revenue and scale clues

  • Revenue sources: $10 donation on the download page, GitHub Sponsors, commercial licenses, sponsor Recall.ai, paid apps Dipper / Flash Metro. Patreon brings only about $0.8/month, so it is not the main income.
  • Specific amounts not found.
  • Our data: US 37%, UK 7%, Australia 5%; direct visits 36.5%.

Confidence and gaps

  • GitHub dates, HN data and the Soundflower-replacement narrative have first-hand sources and are credible.
  • Search results were almost entirely irrelevant (the Reddit group returned things like "health"), so evidence could only be filled in from GitHub and HN.
  • Gaps: Devin Roth's personal background, download counts, commercial license revenue, Dipper's price and launch date.
