A university-student developer in Sydney (ItsVams / vams.dev) already ran the big Discord server for the Roblox events scene, "Roblox Events Community" (about 93k members), and the X account @EventsOnRoblox, and the server was already hosting "Clan Battles" team competitions. In 2026 he "moved" that gameplay and that community onto his own site, Gunterverse (event/badge/item tracking + public profiles + leaderboards + clans + Wordle-style mini-games), running a closed beta with access codes first and opening up in July–August 2026. The first users were the "gunters" (Roblox event hunters) from that Discord community, and every official Roblox event since (The Hunt, Egg Hunt, Halloween) pulls the community back to the site to log progress and chase the leaderboard; monetized via Robux/USD supporter memberships.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: Roblox event encyclopedia + personal collection tracker (events, event items, badges, puzzle games), with public profiles, follows, leaderboards, achievements, Gunter Groups teams, Clan Battles, daily mini-games such as Itemdle/Eventdle/Badgedle, user Lists, the Chrome extension "Gunterverse for Roblox," the Discord bot GurtBot, and API access.
  • Developer: vams (Roblox username ItsVams); vams.dev describes him as "Nepal-born, Sydney-based," building "web apps, Discord bots and browser extensions for the Roblox community"; the supporter page says "built and run by one uni student on an i3." Stack: Bun/Express/EJS/MongoDB/Redis. Sources: https://vams.dev/, https://gunterverse.com/supporter
  • Linked channels: Discord server discord.gg/robloxevents ("Roblox Events Community"; on 2026-10-25 the Discord API showed about 93,124 members, 10,314 online); X @EventsOnRoblox (main account) and @Gunterverse; Roblox group "Gunterverse" (owner ItsVams, 507 members).
  • Pricing: Supporter $4.99/month, $9.99/quarter, $24.99 lifetime; Developer $6.99/month, $14.99/quarter, $34.99 lifetime; all payable in Robux; $5 tips also accepted.
  • Domain: WHOIS registration 2026-01-17; earliest Wayback snapshot 2026-08-02.
  • Users: United States 58%, Canada 11%, Brazil 5%; direct 66.4%, social 25.2% (YouTube, X, Discord), search 5%; search terms include roblox the hunt 20 leaderboard and eggtanic badge.

Where the first users came from: the ready-made community of the Discord "Roblox Events Community" (93k members) and X @EventsOnRoblox. Evidence: the FAQ says Clan Battles were "moved" from that server to the site ("Gunterverse takeover"); the homepage and FAQ list only Discord/X/the Roblox group as community entry points; Supporter members can claim a gold role in that Discord via GurtBot `/get_roles`. When the server was created and when this developer took it over not found.

Growth loop

Evidence:

  • Community -> site: the Discord server (93k) + X account funnel traffic; Supporter perks are tied to Discord roles, so Discord activity feeds back into site payments.
  • Event calendar drives return visits: every official Roblox event (The Hunt, Egg Hunt, Halloween Badge Hunt, etc.) gets leaderboards, speedrun boards and badge checklists; search terms "roblox the hunt 20 leaderboard" and "eggtanic badge" map directly to events.
  • Social/competitive mechanics: public profiles (events completed, badge count, item count), follows, leaderboards, achievements, Hall of Fame, Clan Battles, teams (7-person Team) — you need to recruit friends to compete in clan battles.
  • Daily mini-games (Itemdle/Eventdle/Badgedle, Higher or Lower) create daily actives.
  • The Chrome extension embeds features into the Roblox website, forming a second entry point.
  • Monetization: Robux/USD supporter memberships, monthly/quarterly/lifetime.

Speculation:

  • The YouTube social source may be Roblox event YouTubers linking leaderboards/badge pages in guide videos (no specific video found).
  • The September rise in checkout visits coincides with September Roblox events (the site has September event badges such as "Viral Survivor"), i.e. event-season driven.

Revenue and scale clues

  • Stripe checkout visits: 0 in 2026-07, about 4.7k in 08, about 12.9k in 09 (Similarweb bucketed estimates, order of magnitude only).
  • Global rank about 102k; bounce rate 33%, 8.1 pages per visit, 4 minutes on site — a high-stickiness community site.
  • Discord community about 93k members; Roblox group 507; Hall of Fame lists 10 donors.
  • Revenue undisclosed; price points $5–$35; the developer says revenue mainly covers hosting, databases and scraping processes.

Confidence and gaps

  • New site, written from scratch. "Existing audience" is backed by the FAQ's own wording plus the Discord API member count; medium-high confidence.
  • Gaps: when the Discord server was founded and whether vams founded it or took it over later not found; the public launch date can only be pinned to around 2026-07 (official account registered 07-06, first Wayback capture 08-02); X pages could not be opened (402), so post details are summary only; no founder interview.
