Basics

  • Product: real-time odds comparison for Australian racing (thoroughbred, harness, greyhound) across 50+ Australian bookmakers; custom layouts, betting, Alerts; GraphQL API + Python SDK (GitHub betwatch/betwatch-sdk-python, MIT, 4 stars); Discord community; race widget at widget.betwatch.com.
  • Company: Betwatch Pty Ltd (Australia); GitHub org location Australia, no public members; founder not found.
  • Tech: SvelteKit + Supabase + Stripe + PostHog + Sentry (page source 2022-2024).
  • Launch: domain registered 2007-11-03; parked for-sale page 2011-2013, redirected to domain broker gamblingdomains.com 2016-2021 (Wayback); Supabase project key issued 2022-06-21; first Wayback capture of the product homepage 2022-11-04 ("© 2022 Betwatch Pty Ltd").
  • Pricing: homepage only says "Get Started for Free"; page source contains three Stripe subscription price IDs, Premium, API Racing and API Live Racing (from 2023), indicating a paid tier exists, but prices are not public; the API requires a separate subscription priced by data volume, with a free trial (guide.betwatch.com/docs).

Growth loop

  • Evidence:
  • Traffic structure: direct + brand keyword search make up the vast majority, meaning users are "people who know the name" coming back daily to check odds; no social, no major referring sites.
  • Across the 5 given search sets, no Reddit, press, forum or review mentions betwatch.com (the similarly named betwatch.fr is a different football money-flow site).
  • Has Discord, X @BetwatchHQ, GitHub and an API, aimed at "professional/semi-pro racing punters + quant players".
  • Speculation:
  • First users: word of mouth in Australian racing circles (Discord, racing forums, Punters community); racing punters use it at high frequency every day, so retention is naturally high and driven by direct return visits.
  • The short domain betwatch.com is easy to remember, and brand keyword search contains many misspellings (profile), suggesting spread by word of mouth.
  • The API lets the data be embedded in third-party tools and widgets, possibly bringing a small amount of referral.
