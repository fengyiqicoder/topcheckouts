In June 2025 Claude Code blew up among Chinese developers, but connecting directly and paying were both hard from China. PackyCode launched then as a "Claude Code relay", and built trust by posting a public uptime monitor in the Linux.do community and answering questions in a QQ group. The real amplifier was the open-source tool cc-switch, a one-click provider switcher for Claude Code/Codex that later grew to 148k stars. In 2025-09 PackyCode was added as a preset provider in cc-switch, and on 2025-11-10 it became an official sponsor, with an exclusive rebate link (aff=cc-switch) and a 10%-off code shown in the README and inside the app. PackyAPI later turned this playbook into a "developer ecosystem partner program", using cash and credits to buy README recommendation slots from open-source projects and communities, combined with aff affiliate links, to keep catching the upstream traffic of AI coding tools.One-line growth story, compiled by us from public sources; speculation is marked separately below.

Basics

  • Product: An OpenAI-compatible multi-model API relay gateway. One key calls Claude / Claude Code / GPT / Codex / Gemini / Azure OpenAI; just swap the base URL to packyapi. The docs cover integrating CLIs such as Claude Code, Codex and Grok Build.
  • Pricing: Pay as you go, list price about 72% of official; $1 free on signup; first top-up with the "cc-switch" code gets another 10% off.
  • Who is behind it: The footer says "Packy Team" and the /partners page says "operated by PackyCode". The packyapi.ai WHOIS registrant country is CN, so it is judged to be a Chinese team. Company entity and founder not found; no funding seen.
  • Community: For problems join the QQ group; service status is posted on the Linux.do monitoring site check.linux.do/group/Packy.
  • Launch date:
  • packycode.com registered 2025-06-21 (now 301-redirects to packyapi.com).
  • packyapi.com registered 2025-10-17.
  • packyapi.ai registered 2026-05-22.

Growth loop

  • Evidence:
  • Sponsoring a top open-source tool and embedding itself in it: cc-switch presets, a README sponsor slot and in-app promotion, with trackable aff links.
  • A systematic open-source sponsorship program (/partners).
  • Affiliate promotion with aff links: the Gist promo post carries aff=YuAi.
  • Trust endorsement: public uptime monitoring on Linux.do.
  • QQ group support.
  • Referral is 28.4%, of which gitcode.com is the largest (gitcode is a Chinese code host, very likely a domestic mirror page for projects like cc-switch).
  • Speculation:
  • The first users (2025-06~09) most likely came from Linux.do relay/account-sharing threads and QQ group word of mouth; the launch post was not directly obtained.
  • The takeoff point was after entering cc-switch in 2025-09~11, since every cc-switch user sees PackyCode in the provider list.
  • Every time a new upstream model ships or a ban wave hits, a batch of migrating users arrives.

Revenue and scale clues

  • User count and revenue are not public.
  • Being able to hold the exclusive sponsor slot on a 148k-star project over time and run a sponsorship program suggests some cash flow (speculation).
  • Our September number 21,490 is exactly the same as venice.ai and others, likely a tiered estimate from the data source.

Confidence and gaps

  • The two key cc-switch commits (the 2025-09-13 preset and the 2025-11-10 official sponsorship) are direct evidence from git history, so credibility is high. The brand history has double evidence from homepage source comments and WHOIS.
  • The Reddit, viral and TikTok search query groups returned mostly noise; the Linux.do launch post, team identity and sponsorship amounts are still not found.
  • Compliance risk: relay sites often involve reselling accounts or quotas, with a risk of being banned upstream.
  • Second-pass check: takeoff method changed from "new-platform window" to "piggyback on a platform", growth engine from "creators or community" to "referral rewards or affiliates", pure product-driven spread from "mixed" to "no".
