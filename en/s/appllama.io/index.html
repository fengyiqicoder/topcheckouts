Basics

  • Product: a design library of high-revenue iOS apps; the homepage says 76,900+ screenshots from 1,680+ top-grossing apps, updated weekly; searchable by flow (e.g. Text to Speech) and UI element (tab bar, paywall card, progress ring); an MCP service at mcp.appllama.io (Pro only, each call costs 1 credit); open-source agent skills (appllama-usage, appllama-app-design-skill, aimed at Expo/React Native); plus Studio and Public works pages.
  • Team: Product Hunt lists the makers as Jaimin (co-founder, X @jaimintf) and Nikhil Akki (@nikhil_akki, LinkedIn location India, headline "appllama.io | find winning ui/ux for mobile apps and build in a day"). The trademark belongs to Antmind Ventures Private Limited (an Indian private company).
  • Pricing: some screenshots can be browsed free; Pro is about $9-10/month (SaaSHub says $9/month), India pricing INR 1,299/month and INR 11,999/year.
  • Domain: appllama.io registered 2026-04-29 (Namecheap); Wayback first captured it 2026-05-04 (301), and it returns a normal 200 from 2026-08-08.
  • Our data: United States 47.4%, India 14.27%, United Kingdom 7.26%; social 48.9% (X, Facebook, LinkedIn), direct 34.8%, search 9.8% (brand keywords 42.7%); referrals designeer.xyz 3.1%, producthunt.com 0.96%.

Growth loop

Evidence:

  • Product Hunt launch: #5 of the day with 205 upvotes on 08-03; producthunt.com still shows 0.96% in our referrals.
  • X / social: social 48.9% in our data is the largest source (X, Facebook, LinkedIn); the official account and co-founder Jaimin post comparisons of AI building apps on X (such as "GPT-6 Astra vs Fable 5.1, same prompt"), which is content operation aimed at the indie developer circle.
  • Riding the AI agent ecosystem: the open-source skills repo has 3k stars and is listed and reposted by skills directory sites like SkillsMP and skillmap; the MCP page ranks first in search results. MCP calls require Pro, which converts agent users straight into paying users.
  • Referrals from design inspiration directories: designeer.xyz 3.1%, listed on designbookmark.com, various "Mobbin alternatives" lists.

Speculation:

  • The first 1,000 users most likely came from the Product Hunt launch day plus the two founders' X followers (indie developer circles in India and the US); there is no direct data.
  • The skills repo's stars probably burst in mid-two months ago (agent skills were hot), bringing a wave of developer awareness; GitHub is not among the top referrers in our data, so the conversion is speculated to be indirect (people see the repo and then search the brand or arrive from X).
  • Screenshot pages (/flows/xxx, /elements) can be indexed by search and will form a long-tail search source over time; search is only 9.8% for now.

Revenue and scale clues

  • Pro is about $9-10/month / INR 1,299/month; Pro is required to use MCP.
  • The homepage "Trusted by design teams at" shows logos of ChatGPT, Anthropic, Duolingo, LinkedIn, Canva and Strava (self-claimed, not verified).
  • GitHub 3,033 stars; PH 308 followers. Revenue and paying user count not found.

Confidence and gaps

  • Registration date, the Product Hunt launch date and rank, founders, GitHub data and the company entity all have primary sources and are credible.
  • The X posts would not open (402), so only snippets were used; the time distribution of GitHub stars was not obtained (the API needs a login).
  • Gaps: how they warmed up before launch (a waitlist from 2026-05 to 08?), actual views of the X posts, paying user count and revenue.
