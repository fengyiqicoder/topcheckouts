Basics

  • Product: a self-hosted, single-user, MIT-licensed LLM router; one /v1 OpenAI-compatible endpoint with 34–65 free providers and 600–985 model endpoints behind it; smart routing (Thompson sampling added later), automatic 429/5xx fallback switching, key encryption, CLI, Docker, Electron desktop version; states "for personal experimentation only".
  • Pricing: the router is free; Premium Annual $19/year, Premium Lifetime $49 (keeps the model catalog, new free models and quota changes updated in real time). The seller is Neu Software LLC (neu.so, whose blog lists Free LLM API as one of its own products).
  • Author: Tashfeen Ahmed (GitHub tashfeenahmed, PH name Tash Ahmed, X @tashfene), Dublin, senior AI product designer for Microsoft 365 Copilot, personal site tashfeen.me. A side project with no funding.
  • GitHub: https://github.com/tashfeenahmed/freellmapi — as of 2026-10-25, 40,823 stars, 5,505 forks, ~1,010 commits; still releasing almost daily this month
  • Social: official TikTok @freellmapi (short videos like "POV: your LLM API bill is now $0" since 2026-08); official subreddit r/FreeLLMapi.

Growth loop

  • Evidence:
  • First users: the Product Hunt launch (#22, with the author running the comment section himself) + the open-source GitHub repo; 10K stars in two months shows GitHub itself (Trending / star spread) was the initial amplifier.
  • Creator supply: YouTube tutorials (05-27, 08-20), the viral post from an X AI repost account (06-25), and tutorial sites such as CoddyKit / Better Stack / AI Fire / DeepWiki all retell "1 billion / 4 billion / 7.4 billion free tokens" in their titles — the number itself is the spread hook.
  • Open-source copies: many forks and renamed copy repos objectively spread the brand.
  • The official side added a TikTok short-video account later on.
  • Referral traffic is 27.6% (GitHub, tutorial sites), direct 63.3%.
  • Speculation:
  • The three months ago peak was mainly driven by the viral X post at the end of four months ago; many users are from India (40%) and China (18%), which fits the pattern of "free API" being reposted in developer communities in both places (YouTube/Telegram/WeChat official accounts).
  • After self-hosting, free users upgrade to Premium to avoid maintaining the model catalog themselves.

Revenue and scale clues

  • Pricing $19/year, $49 buyout. last month checkout visits were 17K; if 5–10% convert, monthly revenue is about a few thousand to ten-odd thousand dollars (speculation).
  • No public MRR; GitHub star curve: 06-12 about 9.9K → 08-24 19.6K → 08-30 22.4K → 10-25 40.8K.
