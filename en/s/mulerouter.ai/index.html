Basics

  • Product: multimodal + LLM API gateway ("World's FIRST Skills-Native AIO API platform"), with unified authentication to call Wan, Qwen, GPT, Nano Banana, Kling, MiniMax, Grok, GLM and others; its own "Spark" series are low-cost fine-tuned versions of Wan video models; provides an npm CLI `mulerouter` and an Agent Skill for Claude Code.
  • Who makes it: the site footer only says "© 2025 MuleRouter", with no company named. Related evidence: GitHub "Get Started" points to the openmule organization (whose blog field is mulerun.com, created 2025-06-16), and the skills repo supports both MuleRouter and MuleRun gateways, sharing the MULEROUTER_API_KEY variable. MuleRun is an Alibaba Cloud internal venture led by Alibaba Cloud VP Chen Yusen (co-founder of Chaitin Technology) - source https://ai.miraheze.org/wiki/MuleRun. So MuleRouter is most likely an API product of the MuleRun/Alibaba Cloud team (speculation, not stated officially).
  • Pricing: usage-based billing, prices not public on the site, the pricing page returns 404.
  • Domain: mulerouter.ai registered 2025-11-04 (RDAP), with a registrar transfer on 2026-01-13; first Wayback snapshot 2025-12-11 (the homepage then featured Qwen3 Max, Wan 2.5 preview and Nano Banana Pro).
  • Traffic (profile file): US 37%, Indonesia 12.8%, India 11.9%; referral 47%, direct 39.8%, AI assistants 8%; search terms include "mulerouter pricing" and "wan2.5-i2i-preview".

Where the first users came from: no launch post or announcement was found. The traceable clues are: (1) the homepage has always put Alibaba's newest Wan/Qwen preview models in the most prominent spot, and the search terms include a specific model name "wan2.5-i2i-preview", showing some developers arrived by new model names to call them; (2) referral traffic is 47%, and since the skills repo also serves MuleRun, referrals are presumed to come mainly from the MuleRun ecosystem and Alibaba model docs/partner pages (speculation, referring site names not obtained).

Growth loop

Evidence:

  • Catching new-model windows: whenever a popular model appears (Nano Banana Pro, Wan 2.5/2.6/3.0, GPT Image 2), it lists it and marks it "New" on the homepage, with each model getting its own landing page (60+ /models/ pages in the sitemap).
  • Agent ecosystem integration: one-command install from the Claude Code plugin marketplace, and an npm CLI.

Speculation:

  • It relies on traffic/customer relationships from MuleRun (600K+ sign-ups) and Alibaba Cloud to send traffic over, hence the high referral share.
  • Low prices on Wan/Qwen (including its own Spark fine-tuned versions) attract cost-sensitive developers in Indonesia and India.

Revenue and scale clues

  • No public prices or user numbers; Discord 193 members and skills repo 19 stars, so the community is very small.
  • The main value may be overseas distribution for Alibaba's models rather than standalone profit (speculation).

Confidence and gaps

  • New site, written from scratch. The search results were almost entirely unrelated pages (speed-test sites, OpenRouter reviews), so evidence was filled in only from the site, GitHub API, Discord API, Wayback, RDAP and MuleRun's wiki.
  • The relationship between MuleRouter and MuleRun/Alibaba Cloud is inferred from the shared GitHub organization and shared skills, not stated officially.
  • Gaps: the operating company entity, pricing, referring source sites and user numbers were not found.
