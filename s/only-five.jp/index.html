基本信息

  • 产品：创作者上架照片或视频，每件只卖先着 5 名；买家下单后，创作者在照片上手写写给该买家的留言（或录专属留言视频），以数字数据交付（不寄实物）。可"即时贩卖"或"定时预约贩卖"，官方建议配合 Twitter 告知开卖时间（note 官方贩卖方法，2023-01）。早期规则：每名成员每天最多 3 帖，即每天最多 15 单（QOOLONG 博客，2020-04）。站点标"あなただけの写真集""特許申請中"，有日/英/马来/韩语界面。
  • 价格：按商品各自定价。粉丝博客估计照片约 1,000–2,000 日元、视频约 3,000 日元（in-the-water.com，作者印象，非官方）。信用卡（Stripe）支付；早期无卡用户被引导用 Bandl Card。
  • 运营：株式会社DHN（ONLY FIVE事業部），东京都新宿区荒木町13-4。创始人、融资未查到（不是本次重点）。
  • 创作者准入：法人/事务所账户 + 个人（自由职业，含只做 SNS 活动的人）账户，审核制（note 官方，2023-01-08）。
  • 同类竞品：yell 公司的 Marche（marche-yell.com），粉丝博主称"几乎一样"（allthefeel，2022-04）。

增长循环

  • 有证据:
    • 第一批供给 = 偶像事务所整团入驻（QOOLONG 一家就带了两个团），动机是新冠期间 Live 停摆、切奇收入归零；第一批买家 = 这些团的现有粉丝，由偶像在 Twitter 告知开卖时间引流（QOOLONG 博客、官方 note 均建议"Twitter等で告知"）。
    • 粉丝侧二级传播：粉丝博客写教程/评测（2020-04 起），海外粉丝 subreddit 讨论（2020-05）。
    • 平台站内不做发现（搜索页为空），流量 = 创作者外部引流；渠道档案：直接 47%、社交 29%（X 为主）、搜索 19%（搜创作者名 + "onlyfive 支払い方法"）。
    • 平台运营手段：销售排行活动（2023 winter campaign）激励创作者卖力宣传。
  • 推测:先着 5 名的稀缺性 → 开卖即抢光 → 粉丝在 X 晒出手写留言 → 刺激同担和其他偶像跟进入驻；事务所之间口碑扩散（一家事务所整团入驻 = 一次批量供给）。

收入与规模线索

  • 无公开收入数据。早期每成员每天最多 15 单的上限说明单个偶像日 GMV 约 1.5–3 万日元（按 1,000–2,000 日元/单，推测）。
  • 上个月收款页 1.7 万访问，月 GMV 可能在数百万日元量级（推测）。
  • 分成：QOOLONG 博客称货款先全部进运营方，事务所自定成员分成比例；平台抽成比例未公开。

可信度与缺口

  • 中。起家时机和第一批供给（偶像事务所因新冠入驻）有一手博客证据；精确上线日、平台抽成、创作者数量、DHN 创始人未查到。Reddit 帖仅摘要。
  • 二次补查：起飞方式从"未查到（推测已有圈子迁移）"改为"外部事件顺风"，补上 2020-04 新冠期间偶像事务所整团入驻的一手证据、2023 年开放个人创作者和排行活动、主要创作者类型（地下偶像 + 写真偶像，非成人向）。
