第一批用户从哪来：搜"iloader"的人。上游开源工具 2025-11 起在 SideStore 社区、r/sideloaded、YouTube 侧载教程里传开，品牌搜索量起来后，iloader.site 凭 .site 精确匹配域名 + 大量教程页排到搜索前列，截走一部分品牌流量。

新用户从哪来：继续是品牌搜索（79%）+ 长尾侧载词（"TikTok Mod 侧载 iPhone 2026"、"iloader скачать"等多语种词），以及 YouTube/Reddit 教程里误链的流量。

增长循环

有证据:

  • 上游热度 → 品牌搜索 → 仿冒站截流：搜索 81%、品牌词 79%；issue #648 证实它排在"iloader"搜索第一。
  • 内容占位：IPA 目录、教程、博客铺长尾关键词。
  • 变现：$10"捐款"墙 + Premium IPAs。

推测:

  • 随官方工具更新频繁、下载量暴涨（单版本十几万次），站点流量同步上涨；一旦 Google 处理冒充举报或官方站排名上来，流量会快速流失。
  • 俄语、意大利语搜索词说明内容做了多语种 SEO。

收入与规模线索

  • $10/次"捐款"；Premium IPAs 价格未知。流量规模未单独核实（档案只给比例）。
  • 上游官方累计 Release 下载约 490 万次，是它能截流的池子上限参考。

可信度与缺口

  • 新站，从零写。"仿冒站 + $10 捐款墙"有官方仓库 issue 原文和下载页原文双重证据，可信度高；上游时间和下载量来自 GitHub API。
  • 注意：分类上它不是一个"自己发家"的产品，而是寄生在开源项目品牌搜索上。
  • 缺口：运营者身份、实际付费人数、Reddit 揭发帖原文（打不开）、Google 是否已降权。
