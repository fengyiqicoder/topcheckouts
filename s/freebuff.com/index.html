基本信息

  • 产品：Freebuff，免费编程 Agent，包括 CLI（`npm i -g freebuff`）、桌面端、Freebuff Web / App Builder（由 Vly 改名而来）、研究聊天和移动端。内置 9 个子 Agent，模型是 DeepSeek v4、MiMo 2.5 Pro、GLM 5.2、Minimax M3，找文件用 Gemini 3.1 Flash Lite；也可以接用户自己的 Claude Code 或 ChatGPT 订阅。只有 25 个以上国家能用完整模型，其余地区限制为 Flash 模型、每天 6 个一小时会话。变现方式是 CLI 回合之间插入纯文字赞助广告（云、托管、开发基础设施）；无广告的付费版是 Codebuff Pro，面向组织。
  • 团队：Codebuff（原名 Manicode，因商标纠纷改名），YC F24，联合创始人 James Grugett、Brandon Chen；Freebuff Web 负责人 Victor Cheng（原 Vly）。融资约 150 万美元，投资方是 YC、Pioneer Fund 等（来自 wiki，无原始引用）。
  • 域名 freebuff.com 是 2000 年注册的老域名，应是买来的；早期 Reddit 帖用过 freebuff.ai。

增长循环

  • 有证据:已有用户池迁移。Vly 老用户自动并入 Freebuff Web；Codebuff 的开源和 YC 圈带来引荐流量（我方数据里 vly.ai 占 6.3%、ycombinator.com 占 4.5%）。
  • 有证据:程序化 SEO。几十篇"免费替代 X"和"换过来省了 $N"的文章，专门截流 Claude Code、Cursor、Lovable 等付费工具的搜索。不过当前搜索流量里品牌词占 89%，说明这些文章带来的非品牌流量有限。
  • 有证据:"完全免费"是最强的传播点。AI 工具类 YouTube 和 Reddit 博主主动做内容，社区自发做 OpenCode Provider 集成。
  • 有证据:邀请链接 `?ref=`，用户主动在 Reddit 发（奖励内容未查到）。
  • 有证据:Reddit 多个版块同日出现雷同帖，有运营刷帖痕迹。
  • 有证据:双边飞轮雏形。用户数（"50 万开发者"）直接被当作卖点卖给广告主（Freebuff Ads）。
  • 推测:印度、印尼和拉美学生或接单者之间口口相传（官博印度案例、非英语反馈占比上升、我方数据印度占 23%）。
