增长循环

有证据:

  • 创始人爆帖起盘：一条名人视频翻译 demo 推文 354 万浏览，产出本身（名人说外语）就是传播素材。
  • 开源仓库 README 把 1.3 万星仓库的访客导向商用版。
  • API 嵌入 Kapwing、Sieve 等平台，以及 Premiere/DaVinci/ComfyUI/ChatGPT 插件：别人的用户群成为分发渠道。
  • Startup Program / Creator Partner Program 送额度拉开发者和创作者。
  • 博客 SEO 文（"AI lip sync tools"、名人对口型 meme 等）。
  • 流量面：直接 73.8%、搜索 22.1%（95.8% 品牌词）、引荐 workatastartup.com 6% —— 新客主要靠品牌认知而非长尾搜索。

推测:

  • 用户用 sync. 做的多语种/meme 视频在社媒传播带来新创作者（产出无明显水印，属话题传播）。
  • Show HN、PH 首发都没起量（5 分、#11），说明首发平台不是主要来源。

收入与规模线索

  • 13 人团队；$5.5M 种子；按秒计费。YC 页"thousands of developers"。未查到公开 ARR/用户数。

可信度与缺口

  • 二次补查：查到 Prady 2023-07-16 的爆帖（354 万浏览）就是 YC 页所说的"mega-viral app"，起飞方式由"首发平台"改为"主播或媒体点燃"（创始人自己的推文点燃）；Show HN 仅 5 分，证明首发平台不是来源；补充 PH sync-3 首发 #11 和 Creator Partner 计划。
  • 爆帖后的注册转化数字、是否有 A 轮均未查到；域名从 synclabs.so 切到 sync.so 的时间未核实。
