基本信息

  • 产品：C.vélo 会员系统——注册、登录、续费年卡、上传身份证和住址证明、查站点地图、CGV；主站 c-velo.fr 负责介绍和新闻。会员系统由 shooga.ca 提供（profile 档案）。
  • 谁做的：SMTC-AC（克莱蒙费朗都市圈公共交通联合管理机构）提供，Citybike France 运营（2021 年起），2013 年时首页页脚列 T2C、VELOGIK、SMTC。
  • 服务内容：自助公共自行车（年卡 0 €——由 Clermont Auvergne Métropole 承担 25 € 价值；7 天 €7；1 天 €2）、长租自行车（€10/天起）、电动长尾车、电动车试用、C.BOXvélo 安全停车箱；可用 App、公交卡或临时码取车。押金/丢车罚款 €200（profile 档案）。
  • 域名：c-velo.fr 注册于 2013-04-30（RDAP）；主站 Wayback 首个快照 2013-06-29；membres 子域首个快照 2023-05-29。
  • 流量（profile 档案）：法国 100%；引荐 45.3%（主要来自主站）、直接 41%、搜索 8.2%（只有"cvelo clermont""c.velo"品牌词）。

第一批用户从哪来：市政机构直接投放——2013 年开通时由 SMTC 宣传，站点设在城市街头，目标就是本地居民；后来与公交卡打通、年卡由都市圈补贴为 0 €。会员站的用户全部来自已有 C.vélo 用户的续费和新注册（引荐 45% 来自主站）。

增长循环

有证据:

  • 公共补贴：自助车年卡对用户 0 €（都市圈承担 25 €）。
  • 与公交系统捆绑：公交卡可直接取车，折叠电动车试点只开放给持 T2C 公交卡的用户。
  • 线下站点和活动（自行车节、无车日、"重新上车"活动）做本地曝光。

推测:

  • 年卡免费化和疫情后的骑行热潮是近年会员增长的主要原因（推测，未查到会员数）。

收入与规模线索

  • 公共服务，主要靠财政补贴；收入只来自短期通票和长租车费用。站点数、车辆数、会员数均未在官网列出。

可信度与缺口

  • 新站从零写。搜索结果几乎全是无关测速站；证据来自主站存档新闻、RDAP 和 Wayback。
  • 该站本质是市政服务会员后台，"发家"框架不太适用；分类里"增长引擎"填未查到。
  • 缺口：会员数、站点/车辆数、年卡何时改为 0 €、Velogik 到 Citybike France 的招标细节都未查到。
