基本信息

  • 产品：生成式媒体 API 聚合平台（图片、视频、音频），一个 x-api-key 可调用 100 到 500 多个第三方模型（Veo、Kling、Seedance、Flux、Midjourney、Suno、Runway、Wan 等）。另有 playground、工作流编辑器、Agents、MCP、CLI 和白标服务。按次付费，无订阅。主打"最低价 API"，经常给某个模型打折（如 Seedance 2.5 打 72 折）。
  • 公司：Vadoo Internet Services Private Limited，印度班加罗尔，2020-05-23 注册，2019 年起步。创始人 Anil Chandra Naidu Matcha、Ankur Singh。早期产品是 vadoo.tv 视频托管、P2P 视频分发，后来转做 AI 视频生成工具。
  • 融资：Entrepreneur First、JioGenNext 等早期小额投资，合计约 $55K–80K（The Company Check / CB Insights），后续没有公开融资。
  • 上线：muapi.ai 域名 2025-04-10 注册，Wayback 最早快照 2025-07-08。

增长循环

有证据:

  • 开源替代仓库当诱饵，后端绑定 muapi：README 挂 "Powered by MuAPI" 徽章，链接带 utm_source=github，项目要跑起来就需要 muapi key。
  • 白标循环：README 直接推销"把这个开源应用作为你自己品牌的 AI studio 卖给客户"，白标 $49/月起，加价的部分归开发者。下游创业者变成 muapi 的分销渠道，他们的终端用户每生成一次都在消耗 muapi 的额度。
  • 推荐计划：推荐人拿被推荐人首次充值的 10%（以额度发放，15 天冻结期，每月上限 $500），被推荐人首充多给 5%。
  • 每个热门新模型都抢先做 API 封装仓库和模型落地页（muapi.ai/kling-4 这种"即将上线"页），吃搜索流量。

推测:

  • 主要国家是印度、社交来源以 YouTube 为主，可能和印度 AI 教程类 YouTuber 演示"便宜的 Veo/Kling API"以及开源项目有关，没找到具体视频。
  • 付费页访问稳定在每月约 3.9 万，说明已经进入稳定的充值复购期。

收入与规模线索

  • 按量计费，没有公开 MRR 或用户数。白标 $49/月起。
  • GitHub 资产：Open-Generative-AI 约 30.8K 星，个人号加 SamurAIGPT 组织合计 5 万星以上。
  • 团队很小（早期融资不到 10 万美元），没有公开收入数字。

可信度与缺口

  • 公司归属和 GitHub 获客方式有一手证据（官网 about、GitHub API、README），可信度高。
  • 缺口：创始人的公开访谈、muapi 真实收入、各仓库 star 的增长曲线（stargazers API 需要登录）、起飞的确切月份都没查到。Reddit 抓取被拦截。
