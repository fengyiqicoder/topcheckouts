基本信息

  • 产品：多模态生成（图 / 视频 / 音频 / 3D / LLM）推理托管平台，宣称 1000+ 模型、一个 API、低延迟、无冷启动。按量计费。
  • 公司：WaveSpeedAI，官网 about 写"2025 年由 CEO Zeyi Cheng 创立、总部新加坡"（地址 3 Phillip Street, Singapore）；Preqin 记为杭州，团队应为中国背景、新加坡注册。
  • 创始人：成泽毅（Zeyi Cheng），开源库 stable-fast / ParaAttention / Comfy-WaveSpeed 作者，此前在一家硅谷 AI 基础设施公司负责推理工程（报道称他把那家公司的图像生成推理性能提了 10 倍）。联创兼 CTO 李样兵（英文名 David Li），做过美菜网、深势科技。
  • 融资：2025-04-15 宣布完成数百万美元天使轮（36Kr / PingWest），没披露投资方。没查到 A 轮。
  • 域名注册：2025-01-16（GoDaddy WHOIS）；Wayback 最早快照 2025-01-19。

增长循环

有证据

  • 开源 → 托管：3 个高星仓库的 homepage 都指向 wavespeed.ai，ComfyUI 用户装节点时就看到品牌。
  • 新模型截流：每有热门模型（Wan、Hunyuan、Seedance、Seedream、Nano Banana）就上架，同时发博客 / HN / X，多语种博客承接"某模型 API"的长尾搜索（Organic Search 是第二大渠道，与此吻合）。
  • 联盟分佣：10% 返佣，每个客户封顶 $150，Tolt 追踪，面向 YouTuber、教程作者、Newsletter、开发者（社交流量以 YouTube 为首，与此吻合）。https://wavespeed.ai/static/affiliate
  • 另有 "Be a Creator" 创作者计划（细节未查到）。
  • B 端集成：about 页列出 Freepik、Novita AI、MiniMax、Draw Things 等"信任方"，这些下游产品的用户会间接用到它。

推测

  • 开发者把 WaveSpeed 的 API 写进自己的开源项目、ComfyUI 节点和教程代码，下一个开发者照着用就成了新用户（"代码样例即分发"）。
  • 公开模型页 / 示例作品页带有一定 UGC 展示属性（已知机制标签是 public_profile_leaderboard，但没查到具体的公开排行榜）。

收入与规模线索

  • 官网自称 1M+ 用户、1000+ 模型。
  • 没有公开 MRR；Latka 也没有收入数据。
  • 融资：2025-04 天使轮，数百万美元。
  • 付费页访问量 4–6 月均约 23 万、9 月约 19 万，处于高位但在回落，可能是新模型热点在轮换。

可信度与缺口

  • 创始人背景、开源仓库时间、域名时间、融资都是硬证据。
  • 缺口：Reddit 被 WebFetch 屏蔽，没拿到 r/StableDiffusion / r/comfyui 上 Comfy-WaveSpeed 首发帖的日期和热度；第一批付费用户来源没有创始人自述；1M 用户是官方口径。
