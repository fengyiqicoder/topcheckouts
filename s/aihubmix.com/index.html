基本信息

  • 产品：AI 模型 API 聚合网关，710+ 模型（文本、图像、视频、音频），兼容 OpenAI / Anthropic / Gemini 协议；按量计费、无会员；有免费模型（官方称 27+ 到 64 个）、企业私有化部署版、状态页、发票系统、Vercel AI SDK provider。
  • 自述优势：Azure、AWS、GCP 官方授权合作伙伴；服务器和数据库在美国 Azure；接受支付宝和 Stripe（GitHub README）。
  • 团队：运营主体和创始人未查到；早期 GitHub 仓库账号 akakenle（2023-12-17 建），面向中国开发者（首版官网只有中文描述"大模型代理商"）。备用域名 api.inferera.com。
  • 域名：2023-12-03 注册（RDAP），Wayback 首次抓取 2023-12-16。

增长循环

有证据:

  • 嵌入开源客户端：Cherry Studio 内置（2024-07 起）、AstrBot README 推广码链接、各种 AI 编程工具接入文档。
  • 给开发者的返利：APP-Code 9 折换署名；aff 推广码。
  • 搜索承接：我方数据非品牌词有"cc switch""ox alpha"等开发者工具名（新客 SEO 约 21%），说明用户在找工具配置教程时被它的文档页接住。
  • 目录和测速站：toolify.ai 引荐 2.7%、LMSpeed 等测速站收录；飞书（feishu.cn）引荐 3%，可能是国内团队文档里的配置说明。
  • 免费模型做入口：注册即可调用免费模型。

推测:

  • 第一批用户是 2023 年底拿不到 OpenAI API 的国内开发者，通过 GitHub、V2EX、知乎、开源项目 README 口碑找到它（未看到具体帖子）。
  • Claude Code 等 Agent 编程工具 2025 年爆发后，"国内怎么用 Claude Code"的需求是第二波增长；cc-switch 词说明这一点。
  • 美国 11.8%、印度 10.9% 流量说明多语言文档和"免费模型"开始吸引海外开发者。

收入与规模线索

  • 按量计费，模型售价示例：Claude Opus 5.5 $4/$20 每百万 token、GPT 6.1 Sol $2/$10，部分限时 7 折。
  • 我方数据：中国 26.4%、美国 11.8%、印度 10.9%；直接访问 52.4%（老用户在控制台直接充值调用）。
  • 营收、用户数未查到。

可信度与缺口

  • 上线时间、Cherry Studio 集成时间、APP-Code 机制、开源项目推广链接有一手证据（GitHub、官方文档）。
  • 搜索结果大多是无关的 AI 工具榜单；没找到创始人访谈或首发帖。
  • 缺口：运营公司和创始人、第一批用户从哪个社区来、营收规模、aff 推广佣金比例。
