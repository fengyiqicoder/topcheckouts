增长循环

  • 有证据:
    • 首发：Product Hunt 2026-08-06，是唯一有记录的正式发布渠道（MakerStack："Product Hunt launch is the only channel named"）。
    • 推荐返现：邀请一人激活送 $2，新号送 $5 免卡——这正是批量注册脚本出现的原因。
    • 免费模型档：9 月起"免费 DeepSeek"被 X 博主、awesome 免费清单、中文/德文/俄文薅羊毛和测评站反复转载，成了主要新客入口；社交来源 X、YouTube、Reddit、Threads。
    • 第三方检测站（BazaarLink、ModelVerify）收录，进入 API 中转站比价圈。
  • 推测:
    • 印尼/印度占比高，说明免费额度在东南亚、南亚开发者群（Threads、Telegram、YouTube 教程）里传播。
    • 用低价 Agent Pass 把白嫖用户转成小额订阅，规模靠量。

收入与规模线索

  • 无公开用户数和收入。
  • PH 约 90 票、134 关注者，量级很小；真正量来自免费档转发。
  • 收入模式：按量预付费+低价订阅；免费档成本靠上游免费模型（DeepSeek、MiMo 的免费推广档）兜底，并在用户同意后保留数据。

可信度与缺口

  • 团队、公司、PH 发布日期有 MakerStack 和 PH 页面佐证；PH 页把日榜链接指向 10-24，和 MakerStack 的 8-06 矛盾，以 MakerStack 当天测评为准。
  • Reddit 创始人原帖、X 爆款帖都打不开，只有摘要；转发量不明。
  • "免费档带来主要增长"是根据时间线和来源国推断，没有官方数字。
