基本信息

  • 产品：跨平台（Win/Mac/Linux/Web/iOS/Android）AI 聊天客户端，可以自带 API Key 接 OpenAI/Claude/Gemini/DeepSeek/Ollama 等，也卖自家模型额度订阅 Chatbox AI；支持 MCP、知识库、Work Mode。
  • 作者：Bin Huang（GitHub Bin-Huang，PH @benn_h），中国开发者，起初是单人项目；仓库现已迁到 chatboxai 组织。
  • 主体：官网 llms-full.txt 写明发行方是 Mediocre, LLC（美国 LLC）。融资未查到。
  • 开源：社区版 GPLv3；官网推荐闭源的"官方版"。

增长循环

  • 有证据:
    • 开源 + GitHub 星标，被各类 awesome 列表、教程、第三方测评收录；官网 llms-full.txt 自己也把"GitHub stars, Product Hunt reviews, third-party tutorials"列为口碑来源。
    • 第三方教程（尤其是 DeepSeek 本地部署）把 Chatbox 写成必装步骤，读者直接去官网下载。
    • 模型厂商的接入文档导流：引荐流量里 volcengine.com 占 5.77%、qianwen.com 占 4.59%、github.com 占 4.21%。
    • 搜索 26% 中 98.2% 是品牌词，说明新客多是从别处听说之后再搜。
  • 推测:
    • 免费 BYOK 客户端把用户装进来，再在 App 里推"Chatbox AI"模型订阅（Lite $3.99/月起）做转化。国内用户买不到海外 API，订阅是"一个账号用多家模型"的捷径，这能解释收款页访问主要来自中国。
    • 名气大到出现了仿冒站（LinkedIn 上有人警告一个叫"ChatBox"的诈骗站收 $59.99），侧面说明品牌词有价值。
