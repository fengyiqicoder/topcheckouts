基本信息

  • 产品：集换式卡牌（以宝可梦为主）鉴定评级 + 超声波封装 + 定制标签（Standard / Colour Match / Ace Label 三种），带 QR 码和 Cypheme 防伪标签；有人口报告（population report）和证书查询。按张收费，约 £12–18/张起（profile 档案）。
  • 用户：英国 TCG 藏家和卖家（英国流量 77%）。2026 年开放国际送评（TikTok 主页"International Submissions now open"）。
  • 团队：媒体报道称"Randolph 是 Ace Grading 背后的人"（GoNintendo）；Tabletop Gaming 报道写公司董事为 Andrew Shane。办公室在英国 Banbury（Nintendo Life 搜索摘要，仅摘要）。Randolph 是英国宝可梦开包 YouTuber，频道体量凭记忆约数十万订阅，未核实。
  • 融资：未查到，看起来是 YouTuber 自有生意。

第一批用户从哪来：Randolph 自己的 YouTube 观众 + 社媒预热（2021-08 Coming Soon 页先挂五个社媒），开放后"Launch Edition"纪念壳制造首发稀缺感；当时 PSA 积压到数月，英国藏家有现成痛点。证据是官网快照，具体首批数量未查到。
新用户从哪来：卡牌 YouTube/TikTok 的"Ace 评级开箱/出分"视频（带折扣码），二手市场上流转的 Ace 评级卡（品牌搜索 + "ace cert check"），以及 2024-12 盗窃案的主流媒体曝光。

增长循环

  • 有证据:
    • 评级卡带品牌：每张卡的标签 + 证书号在转卖时被买家查验，profile 显示非品牌搜索约 14% 来自"ace cert check"类词。
    • 创作者开箱：多个 YouTuber 发 Ace 出分视频，带 5% 折扣码（创作者有返佣/折扣合作）。
    • 创始人自带受众：Randolph 是 YouTuber，媒体都以"YouTuber 的卡牌公司"来报。
  • 推测:首发时 PSA/CGC 积压是关键外部顺风；"好看的壳和标签"本身就是为拍视频、晒图设计的，适合开箱内容传播。

收入与规模线索

  • Trustpilot 约 930 条评价（2026 摘要）；被盗卡牌价值约 £25 万 / $31.5 万，说明在手送评量大。
  • 按 £12–18/张推算，收入规模未查到直接数字。

可信度与缺口

  • 上线时间来自 Wayback 快照，可信度高；Randolph 与公司关系来自媒体报道，可信度中高；Randolph 频道体量、首发送评数量、营收都没查到。BBC、IGN、Reddit 原文都打不开，只用了摘要。
  • 新站，从零写。
