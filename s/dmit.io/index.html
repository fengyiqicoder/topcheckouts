增长循环

  • 有证据:
    • 新用户从哪来：(1) 返佣：WHMCS 推广链接 dmit.io/aff.php?aff=xxx 遍布测评博客（vps234、idcspy、zhujiceping）、GitHub 批量仓库、Google Sites；(2) 中文技术社区口碑：引荐里 linux.do 3.27%、dmitea.com 2.82%，NodeSeek 补货监控帖；(3) 品牌词搜索：搜索 20%，其中品牌词 89.3%（dmit、dmit官网），直接 73.4%，说明大部分人是在圈子里听说后直接来；(4) 稀缺营销：限量款只在补货或黑五放出，用户自发抢购和转卖。
    • 新需求顺风：AI 时代用户需要"干净的美国 IP 访问 OpenAI 等服务"，DMIT 是热门选项（LowEndTalk 滥用警告帖为侧面证据）。
  • 推测:第一批用户来自 2018 年 hostloc 等中文 VPS 论坛对"回国线路"的讨论，没找到首发帖。2026 年成批出现的 GitHub 评测仓库是返佣客户做的 SEO 农场，不是官方行为。
