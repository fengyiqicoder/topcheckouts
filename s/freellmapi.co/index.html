增长循环

  • 有证据:
    • 第一批用户：Product Hunt 首发（#22，作者亲自运营评论区）+ GitHub 开源仓库；两个月 1 万 star，说明 GitHub 自身（Trending/star 传播）是最初的放大器。
    • 创作者供给：YouTube 教程（05-27、08-20）、X AI 搬运号爆帖（06-25）、CoddyKit/Better Stack/AI Fire/DeepWiki 等教程站，标题都在复述“10 亿/40 亿/74 亿免费 token”——数字本身就是传播钩子。
    • 开源复制：大量 fork 和改名复制仓库，客观上扩散了品牌。
    • 官方后期补 TikTok 短视频号。
    • 引荐流量占 27.6%（GitHub、教程站），直接 63.3%。
  • 推测:
    • 7 月峰值主要由 6 月底 X 爆帖驱动；印度（40%）和中国（18%）用户多，符合“免费 API”在两地开发者社群（YouTube/Telegram/微信公众号）被搬运的模式。
    • 免费用户自托管后为省去维护模型目录而升级 Premium。

收入与规模线索

  • 定价 $19/年、$49 买断。9 月收款页 1.7 万访问，若 5–10% 成交，月收入约数千至一两万美元（推测）。

可信度与缺口

  • 二次补查：补上首发是 Product Hunt（2026-04-22/23，#22，约 87 票）而非之前推测的 HN；补上 star 增长曲线、2026-05-27 YouTube 和 2026-06-25 X 爆帖两个点燃点、官方 TikTok、Neu Software 与 neu.so 的关系。起飞方式统一为选项内的“首发平台”（PH + GitHub）。
