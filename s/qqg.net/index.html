增长循环

有证据:

  • 50% 推介返佣 + 6 折优惠码，测评站和推广者带链接导流；引荐里有 VPS 测评站。
  • X 上有推广（论坛网友目击）；社交来源 24.5%。
  • 超低年付价（$10–12.99）制造话题，引发论坛讨论。

推测:

  • 循环是"测评站发文拿返佣 → 用户买低价年付 → 用户在论坛晒/问 → 更多测评"，但口碑负面（失联、MTU 问题、跑路疑云），很难形成正向口碑。
  • 用三字母老域名提升可信度、掩盖新品牌身份。

收入与规模线索

  • 无收入数据。主力是 $10–13/年的低价年付，加独立服务器和高防。流量里中国占八成。论坛反馈规模很小（"野鸡云，没听过"）。

可信度与缺口

  • 新站从零写。NodeSeek 两帖 403 打不开，只用摘要；LINUX DO 两帖用 JSON 接口读到了原文。
  • FAST NETWORK LIMITED 的注册信息、老板身份、"换名跑路黑历史"均未核实，仅论坛网友说法。
  • 档案"新客来源：病毒传播"更准确的说法是返佣驱动的测评站推广。
