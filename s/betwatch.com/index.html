基本信息

  • 产品：澳洲赛马（纯种马、轻驾车、赛狗）实时赔率比价，50+ 家澳洲博彩公司；自定义布局、下注、提醒（Alerts）；GraphQL API + Python SDK（GitHub betwatch/betwatch-sdk-python，MIT，4 星）；Discord 社区；赛事小组件 widget.betwatch.com。
  • 公司：Betwatch Pty Ltd（澳洲），GitHub 组织地点 Australia，无公开成员；创始人未查到。
  • 技术：SvelteKit + Supabase + Stripe + PostHog + Sentry（2022-2024 页面源码）。
  • 上线：域名 2007-11-03 注册；2011–2013 是停放待售页，2016–2021 跳转到域名经纪站 gamblingdomains.com（Wayback）；Supabase 项目 key 签发时间 2022-06-21；2022-11-04 Wayback 首次抓到产品首页（"© 2022 Betwatch Pty Ltd"）。
  • 定价：首页只写"Get Started for Free"；页面源码里有 Stripe 的 Premium、API Racing、API Live Racing 三个订阅价格 ID（2023 年起），说明有付费版，具体价格未公开；API 需单独订阅，按数据量计价，可免费试用（guide.betwatch.com/docs）。

增长循环

  • 有证据:
    • 流量结构：直接+品牌词搜索占绝大多数，说明用户是"知道名字的人"天天回来看赔率；没有社交、没有引荐大站。

    • 有 Discord、X @BetwatchHQ、GitHub、API，面向"职业/半职业赌马人+量化玩家"。
  • 推测:
    • 第一批用户：澳洲赌马圈（Discord、赛马论坛、Punters 社区）口碑；赛马赌客每天高频使用，留存天然高，靠直接回访。
    • 短域名 betwatch.com 本身好记，品牌词搜索里大量拼错写法（档案），说明是口头传播。
    • API 让数据被嵌进第三方工具和小组件，可能带来少量引荐。
