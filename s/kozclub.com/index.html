增长循环

有证据:

  • 付费投放基础设施：首页挂 Google Ads 转化标签（AW-17360833489）和 Meta Pixel（fbq），报名按钮统一指向 Fillout 表单并带 canal=lp 参数做渠道归因——典型的"落地页 + 买量"结构。
  • 口碑/品牌搜索：品牌词占搜索 75%、直接访问 38%，profile 档案判断新客多为参加者告诉同事后搜名字；首页证言写明名字、职位、城市（尼斯、洛桑、安纳西、格勒诺布尔）。
  • 城市扩张：每开一座城就多一批可报名的本地用户，2026-07 已 17 城。

推测:

  • 第一批用户大概是两位创始人在里昂的人脉 + LinkedIn 发帖（社交来源只有 LinkedIn），但未找到创始人帖子。
  • 注册数从 1 万到 3 万的跳涨（2026-07 → 10）可能对应投放加码或媒体曝光，未查到具体事件。
  • 匹配到好同桌 → 再来一次 + 带同事来，是天然的复购和转介绍循环。

收入与规模线索

  • 自报 3 万注册；首页"本周 +147"。若每周约 150 人次付费 × 11.99 € ≈ 每月 7,000 € 左右（推测，"本周 +147"未必是付费席位）。
  • 公司注册资本仅 1,000 €，员工数未申报（NN），属早期小团队。

可信度与缺口

  • 新站，从零写。公司、创始人、上线时间来自法国企业登记 API 和 Wayback 原始快照，可信；注册人数等全是站方自报。
  • 缺口：首批午餐具体日期和城市、媒体报道、创始人 LinkedIn 帖子都没查到；搜索结果全部无关（CVE、健康网站），profile 档案"新客来源=病毒传播"与页面上的付费像素证据并存，起飞方式按页面证据定为"花钱买量"，可信度中。
