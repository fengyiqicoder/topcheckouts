增长循环

有证据:

  • Product Hunt 首发：08-03 当日第 5、205 票；我方引荐里 producthunt.com 仍有 0.96%。
  • X/社交：我方数据社交 48.9% 是第一大来源（X、Facebook、LinkedIn）；官方号和联创 Jaimin 在 X 发 AI 做 App 的对比帖（如"GPT-6 Astra vs Fable 5.1 同一个 prompt"），属于独立开发者圈的内容运营。
  • 搭 AI agent 生态：开源 skills 仓库 3k star，被 SkillsMP、skillmap 等 skills 目录站收录转载；MCP 页面在搜索结果第一位。MCP 调用要 Pro，等于把 agent 用户直接转成付费。
  • 设计灵感目录站引荐：designeer.xyz 3.1%、designbookmark.com 收录、各种"Mobbin 替代品"列表。

推测:

  • 第一批 1000 用户大概率来自 PH 首发当天 + 两位创始人的 X 关注者（印度和美国独立开发者圈），没有直接数据。
  • skills 仓库 star 很可能在 08 月中旬集中爆发（agent skills 热），带来一波开发者认知；GitHub 不在我方引荐前列，推测转化是间接的（看到仓库后搜品牌词或从 X 进来）。
  • 截图页（/flows/xxx、/elements）可被搜索收录，长期会形成搜索长尾，目前搜索只占 9.8%。

收入与规模线索

  • Pro 约 $9–10/月 / INR 1,299/月；有 Pro 才能用 MCP。
  • 首页"Trusted by design teams at"放了 ChatGPT、Anthropic、Duolingo、LinkedIn、Canva、Strava 的 logo（自称，未核实）。
  • GitHub 3,033 star；PH 308 关注。营收和付费用户数未查到。

可信度与缺口

  • 注册时间、PH 首发日期和名次、创始人、GitHub 数据、公司主体都有一手来源，可信。
  • X 帖子打不开（402），只用摘要；GitHub star 的时间分布没拿到（API 需登录）。
  • 缺口：首发前的预热方式（2026-05 到 08 的候补名单？）、X 帖子的具体浏览量、付费用户数和营收。
