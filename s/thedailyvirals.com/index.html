  • 有证据:大量 TikTok 视频由达人带推荐码推广（搜索摘要提到"用某码送一个月免费""评论区留言送一个月"），也就是联盟 / 推荐返佣驱动；有用户评论说这种推广方式"scammy"，从侧面印证推广密度很高。
  • 有证据（二次补查）：#thedailyvirals 话题 1,004 条帖子；出现"我的视频在 Daily Virals 排第一"这类内容，说明它收录的达人就是天然的传播者（产出带品牌：被收录 → 晒榜单 → 粉丝去看）。
  • 推测:用户 = TikTok 达人 = 天然的推广者。A 用它找到爆款 → 拍出带货视频赚到佣金 → 拍"我用什么工具"的视频 → B 用 A 的码注册。"带货达人推荐带货工具"是一个闭环，和 Daily Virals 自己的内容主题完全重合。
