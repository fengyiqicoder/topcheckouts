基本信息

  • 产品：OpenAI 兼容的多模型 API 中转网关。一个 Key 调用 Claude / Claude Code / GPT / Codex / Gemini / Azure OpenAI，把 base URL 换成 packyapi 即可。文档覆盖 Claude Code、Codex、Grok Build 等 CLI 的接入。
  • 定价：按量计费，标价约 72 折；注册送 $1；首充用"cc-switch"码再打 9 折。
  • 谁做的：页脚写"Packy Team"，/partners 页写"由 PackyCode 运营"。packyapi.ai WHOIS 注册国为 CN，判断是中国团队。公司主体、创始人未查到，未见融资。
  • 社区：遇到问题进 QQ 群；服务状态挂在 Linux.do 的监控站 check.linux.do/group/Packy。
  • 上线时间：
    • packycode.com 2025-06-21 注册（现在 301 到 packyapi.com）。
    • packyapi.com 2025-10-17 注册。
    • packyapi.ai 2026-05-22 注册。

增长循环

  • 有证据:
    • 赞助头部开源工具，把自己嵌进工具：cc-switch 的预设、README 赞助位加软件内推广，aff 链接可追踪。
    • 系统化的开源赞助计划（/partners）。
    • aff 联盟推广：Gist 软文带 aff=YuAi。
    • 信任背书：Linux.do 公开可用率监控。
    • QQ 群客服。
    • 引荐占 28.4%，其中 gitcode.com 最大（gitcode 是国内代码托管，很可能是 cc-switch 等项目的国内镜像页）。
  • 推测:
    • 第一批用户（2025-06~09）大概率来自 Linux.do 中转/拼车帖和 QQ 群口碑，没有直接拿到首发帖。
    • 起飞点在 2025-09~11 进入 cc-switch 之后，cc-switch 每个用户都会在供应商列表里看到 PackyCode。
    • 上游每出新模型或有封号潮，都会带来一批迁移用户。

可信度与缺口

  • cc-switch 的两个关键 commit（2025-09-13 预设、2025-11-10 官方赞助）是 git 历史直接证据，可信度高。品牌沿革有官网源码注释和 WHOIS 双重证据。

  • 合规风险：中转站常涉及转售账号或额度，有被上游封禁的风险。
