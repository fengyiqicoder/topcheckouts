增长循环

  • 有证据:
    • 比赛规则强制"关注 X + 进 Discord + 带话题分享 + 提交作品链接"，参赛作品在 X 上成为广告；平均每 1–2 个月一场杯赛。
    • 创作者计划 CPP（参与杯赛评审）+ note 博主带 share_code 的 PR 教程文 → 创作者带码拉新。
    • 引荐 21.4% 来自 1link.jp、note.com 等，印证 note 文章导流；直接访问 71.5%、品牌词 74.1%。
    • 上线初期即有 AI 绘图圈博主带 #BytePlus 话题集中发作品（创作者种草）。
    • 有去水印开关（免费产出默认带水印）；NSFW 模式带来 "sousaku ai nsfw" 搜索。
  • 推测:
    • 上线初期的创作者种草大概率是 BytePlus/平台方组织的（话题统一、时间集中），未见合同披露。
    • 字节系模型可能拿到更低成本或更早接入，作为卖点。
    • 上三个月尖峰可能与 NSFW 模式传播或新模型上线有关，未查到具体事件。
