基本信息

  • 产品：足球 REST API（实时比分约 15 秒更新、赛程、阵容、事件、积分榜、球员统计、赔率、预测），附免费比分挂件（widgets）；母品牌 API-SPORTS 还有篮球、F1、NBA、NFL 等 API（api-sports.io）。
  • 团队：API-SPORTS Team，法国；创始人姓名未查到；未见融资信息（看似自力更生）。
  • 上线：WHOIS 注册 2018-07-22（OVH，注册人国家 FR）；Wayback 最早快照 2018-11-11。
  • 定价：免费层每天 100 次请求、端点有限；付费 $19/月起。覆盖 1,200+ 赛事，有实时比分、阵容、事件，没有 xG 等高级数据；文档被评为"Excellent"。第三方对比把它定位成"比 Sportmonks（€78/月起）便宜、比 football-data.org（只有 12 个赛事）覆盖广"，推荐用于原型和副业项目（footyapps，2026-02）。
  • 易混淆的同名竞品：apifootball.com、apifootball.co、football-api.com 是不同的公司，搜索 "api football" 时会互相分流（Reddit 上 u/apifootball 账号属于 apifootball.com，不是本站）。

增长循环

  • 有证据:
    • RapidAPI 市场分发 + 排名第一，开发者在市场里直接订阅。
    • 开发者用它做的项目、教程、SDK、课程反复引用 → 新开发者通过搜索/教程进来（搜索占位）。
    • 免费比分挂件让网站主直接嵌入（我方引荐里有 base44.com，AI 建站产物也在嵌它）。
    • GitHub 上有 35 个打了 api-football 标签的公开仓库（比分 App、Fantasy、博彩预测），这些开源代码又成为 LLM 的训练语料和后来者的模板。
    • 我方数据：ChatGPT 引流约 5%，排在搜索之后，开发者问 AI "免费足球 API"时被推荐。
  • 推测:
    • 挂件里带 API-Football 链接/标识（产出带品牌），未核实。
    • LLM 写足球项目代码时默认推荐 API-Football，构成新的 Gen AI 渠道。
    • 世界杯 2026（上 3–4 个月）带来预测/竞猜类项目激增。
    • 尼日利亚占 10.5%、巴西占 11.7%，推测博彩和竞猜站开发者是重要付费人群（r/algobetting 讨论佐证）。
