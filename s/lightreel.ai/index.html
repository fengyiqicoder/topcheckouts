增长循环

  • 有证据:
    1. X 发布视频连发：每做一个新功能就配一条"Introducing the first AI that…"短视频，7-23、8-10、9-17 三次，最后一次 134 万播放，每次都把它在 X 增长圈的声量往上推一截。
    2. 客户（app 创始人、UGC 代理）公开晒"用 Lightreel 找达人 / hook 跑出 X 百万播放"，Lightreel 转发放大。
    3. 被收录进 creatorstoolbox.com 等工具目录；Similarweb 引荐里 creatorstoolbox 占 6.46%，viralbench.ai 占 8.91%。
    4. API + MCP connector 让它被嵌进别人的 AI 工作流，蹭上了 Claude 生态的热度。
    5. fellowship cohort 做社区运营。
    6. 每天的"当日最火 UGC 视频"公开页带来搜索流量。
  • 推测:UGC 圈本身就是"把增长方法论当内容发"的圈子，操盘手发方法论时顺手提工具，等于免费分发；"A major competitor shut down"（Queue 的证言）说明它还接住了竞品倒下后流出来的用户；YouTube 上有"花 $200/月雇了个内容策略师"类测评视频，大概率在讲它（$199 定价对得上），但没打开确认。
