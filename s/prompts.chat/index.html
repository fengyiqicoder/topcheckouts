  • 作者：Fatih Kadir Akın，伊斯坦布尔，Automattic（WordPress 母公司）"Head of Agentic Experience"，GitHub 11,651 关注者，GitHub Star。https://github.com/f

增长循环

有证据:

  • 抢窗口：ChatGPT 发布 5 天就开仓库、10 天就上网页，成为"第一个提示词库"，被大媒体和行业大佬当成标准参考转发。
  • 社区贡献：每条提示词署名贡献者 GitHub ID，贡献者提 PR 后有动力去转发，仓库至今 9,788 次提交、2.2 万 fork。
  • 多端分发：Hugging Face 数据集、CSV 导出、CLI、MCP、Claude Code 插件、Chrome 扩展，把提示词塞进别人的工具链，反向给主站带流量。
  • GitHub 本身是最大流量来源（引荐 27.5%，主要是 GitHub 项目页）。

推测:

  • "awesome 列表"格式在 GitHub Trending 上天然容易上榜，早期 star 暴涨大概率来自 Trending 和 X/Twitter 转发（凭记忆，未核实：仓库在 2022-12 到 2023-01 期间多次登上 GitHub Trending 第一）。
  • 中国开发者通过 gitcode 镜像、知乎文章进入，占访客 9%。

收入与规模线索

  • 无直接收入数字；企业赞助商 8 家（Neon、Sentry、CodeRabbit、Cognition 等），属于开源项目赞助模式。
  • 规模：174.4K star、22.3K fork；profile 档案显示直接访问占 63%，说明有大量回访用户。

可信度与缺口

  • GitHub stargazers 时间接口需要认证，未拿到 star 增长曲线，早期具体在 HN/X 哪条帖子爆发未查到。
  • Forbes 文章原文未打开，只引用 README 中的日期。
  • Reddit r/PromptEngineering 帖子打不开（仅摘要）。
  • 本站是新站，本次从零写；证据来自 GitHub API、README、RDAP/Wayback、dev.to 文章和搜索摘要。
