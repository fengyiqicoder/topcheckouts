基本信息

  • 产品：monid.discover()（按适配度和价格给候选工具排名）+ monid.run()（不用逐家注册即可调用），以 SKILL.md、远程 MCP server 或 CLI 接入；按次从统一余额扣费（约 $0.0013/次 + 10% 平台费，失败不收费），新用户送 $1；有联盟计划；第三方可上架工具。核心引擎 MIT 开源（Deno 2 + TypeScript）。
  • 公司：Monid Inc，Delaware C-Corp，旧金山。CEO Shengkun Ye；Head of Growth Zongrong (Jasper) Li；成员 Feiyou Guo、Zuoyou (Octo) Dang。
  • 融资：2026-09 pre-seed $2.1M；2026-10-06 种子轮 $7.7M（Long Journey Ventures 领投，Madrona、Essence VC、Pioneer Fund、1984 Ventures 跟投），累计 $9.8M（Yahoo Finance）。
  • 社区：X @monidhq、Discord、GitHub monid-ai（主仓库 6.4k star，2026-08-26 创建）、awesome-monid（72 个社区项目）、Agent Hunt 排行榜 monid.ai/rankings（PH 2.5K 关注）。

增长循环

  • 有证据:
    • 第一批用户：PH 首发（04-23）+ 两周后再发 2.0（05-08），说明前 1000 用户主要来自 PH 和 X 的 AI 开发者圈；有专职 Head of Growth。
    • 起飞事件：8 月底开源 + 9 月 1 日黑客松 + 9 月 2 日 PH 当日第一三连发，8 月收款页较 4–6 月均值翻 4.6 倍。
    • 黑客松用 Monid 额度做奖品 → 参赛者必须注册并充值使用 → 作品进 awesome-monid 列表，成为下一批用户的案例。
    • Agent Hunt 排行榜：用平台交易数据给工具排名，工具方有动力转发自己的排名（供给侧带流量），也给 PH 提供了再次发布的由头。
    • 渠道档案：直接 47.5%、社交 39.3%（X 为主）、搜索 7.9%，引荐有 agent-finder.co 等目录站。
  • 推测:开发者把 Monid Skill 写进开源 Agent/模板，别人 clone 后需要 Monid key 才能运行（依赖式传播）；融资新闻（10 月）再带一波媒体流量。

收入与规模线索

  • 自报 400 万+次 Agent 调用（2026-10）；按 $0.0013/次估算工具流水仅数千美元级，但很多付费工具单价更高，加 10% 平台费，实际收入未披露。
  • 8–9 月收款页约 1.7–1.8 万访问/月（多为余额充值）。融资累计 $9.8M。

可信度与缺口

  • 中高。PH 发布记录、黑客松、融资均有页面证据；用户数和收入未披露，前 1000 用户的具体构成（PH 还是 X 帖）没有一手说法。
  • 二次补查：起飞方式从"抢新平台窗口"改为"首发平台"（查到 4 次 PH 发布，04-23 首发即上线月）；补上 CEO Shengkun Ye、$2.1M pre-seed + $7.7M seed、9 月黑客松、Agent Hunt 排行榜和自报 400 万次调用。
