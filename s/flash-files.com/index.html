基本信息

  • 产品：FlashFiles 文件托管，单文件最高 10GB（注册用户）、"永不删除"；免费下载有等待/广告/验证码，Premium 去广告、不限速、支持续传和下载器。
  • 赚钱机制（2022 年 Wayback /earn 页）：
    • PPD 每千次下载：Tier A（美、英、法、西等）$3–$20，Tier D 单列印度 $1–$20，其他国家 $0.5–$1；最低提现 $5，PayPal/Payoneer/亚马逊礼品卡。
    • PPS：推荐用户买 Premium 分 50%（含续费）；推荐上传者再拿其收益的 40%。
    • 条款写"禁止版权和成人内容"，但流量结构说明实际链接大量投放在灰色资源站（见下）。
  • 谁做的：未查到运营方和创始人；页脚"Copyright © 2019 FlashFiles"。域名 2019-11-24 在 Cloudflare 注册（RDAP，隐私保护）。flash-files.com 在 2000–2018 年属于别人（Wayback 有 2000 年起的旧页面），现网盘是 2019 年新主人。
  • 上线时间：2019-11-24 注册；Wayback 2019-12 首次抓到网盘首页（2020-02 版首页已是完整的 PPD 网盘）。
  • 当前（profile 档案）：印度 63.6%、美国 8.9%；直接 58.7%、引荐 41.3%（uplinks24.com、mmsbee27.com、pinkheartmovies.xyz 等资源/短链站）；社交来自 YouTube、WhatsApp Web、Reddit。2024 年起首页挂 Cloudflare 人机验证，Wayback 抓不到正文。

第一批用户从哪来：上传者——被"上传赚钱"吸引的资源发布者；有证据的是 2020-04 资源论坛宣布迁移到 flash-files 存放视频（仅摘要）。下载者全部来自这些上传者铺出去的链接，网盘自身不做获客。

增长循环

有证据:

  • PPD 双边循环：上传者为了分成把链接铺到资源站 → 下载者被等待页/广告劝购 Premium → 推荐人拿 50% 分成（/earn 页）。
  • 引荐流量来自资源站和短链（uplinks24、mmsbee27、pinkheartmovies 等），WhatsApp 私聊转发（profile 档案）。
  • 用户/文件数 2021→2022 年约 3 倍增长（Wayback 首页计数）。
  • 下载者对"绕等待"有强需求（JDownloader、FastForward、Reddit 求破解），说明免费下载摩擦大、Premium 有转化压力。

推测:

  • 印度单列 Tier D 并给大文件高单价，可能是有意吸引印度影视/视频资源上传者，与印度占 63.6% 的流量结构吻合。
  • 引荐站名称显示链接大量用于成人/盗版视频分发，条款的"禁止版权和成人内容"基本不执行；存在被广告联盟或支付渠道封停的风险（/earn 页自己写"广告账户被停则停止付款"）。

收入与规模线索

  • 注册用户：12,199（2021-03）→ 39,349（2022-06）；文件 94,549 → 213,172。
  • 收入来源：下载页广告 + Premium 订阅；具体价格未抓到（Premium 页被 Cloudflare 拦截）。
  • 规模推算无依据，不做估计。

可信度与缺口

  • 新站从零写。搜索结果多是 Flash Player 无关内容；用了 RDAP、Wayback CDX、Wayback 存档的首页/earn/FAQ 页、JDownloader/GitHub 帖。
  • 引荐站和 jollyvids 论坛疑似成人/偷拍或泄露视频资源站，按安全原则没有打开，只用搜索摘要和 profile 档案的站名。
  • t.me/FlashFilescom 是同名游戏 mod 频道，与本站无关。
  • 缺口：运营方身份、Premium 价格、2023 年后的用户数、具体起飞时点。
