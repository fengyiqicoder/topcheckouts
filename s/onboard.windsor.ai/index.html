基本信息

  • 产品：营销/分析/电商数据连接器，350+ 数据源（Facebook、Google Ads、Reddit Ads、Shopify、HubSpot 等）同步到 Google Sheets、Looker Studio、Power BI、BigQuery、Snowflake，以及通过 MCP 接入 Claude、ChatGPT、Copilot、Manus 等 AI 助手；另有多触点归因。onboard.windsor.ai 是注册、选数据源、授权、拿 API key 的入口。
  • 公司：Windsor.ai，苏黎世，2017 年创立；创始人兼 CEO Niklas Kolster（2003 年做过斯堪的纳维亚首家 VoIP 公司，后在 Accenture、eBay 做十多年数据科学）；CTO Octavian R. Corlade，COO Matthias Kraaz（https://windsor.ai/about-us/ ）。2026-01-20 被 team.blue 收购，金额未披露（https://ai.miraheze.org/wiki/WindsorAI ，第三方 wiki）。
  • 定价：免费 $0/月；$19/月起（年付 $228）；$99/月等多档；30 天免费试用（https://windsor.ai/pricing/ ）。
  • 上线时间：windsor.ai 域名注册 2017-12-16（RDAP）；onboard 子域 Wayback 首个快照 2020-09-30；2021-06 主站导航出现"Data onboarding"。
  • 流量（profile 档案）：巴西 17%、美国 9%、印度 9%；直接 55%、引荐 27%、AI 引流 11%；品牌词 55%，非品牌搜索为 0（子域不承接 SEO，SEO 在主站）。

增长循环

有证据:

  • 程序化 SEO：每个"数据源 × 目的地"组合一页（how to connect X to Power BI/Sheets/Looker Studio/Claude），2021 年已开始，现约 2,900 页；子域本身无非品牌搜索，流量从主站这些页面和品牌搜索导入。
  • AI 渠道：Windsor MCP 进入 Claude 连接器目录、ChatGPT 应用，配约 590 个"接入 AI 助手"页面；onboard 子域 11% 流量来自 AI 引流。
  • 从企业演示销售（2018–2019）转向免费档 + $19 起的自助订阅（2020），对标 Supermetrics 打低价（portermetrics 评测标题"自称更便宜的 Supermetrics 替代品"，仅摘要）。
  • 开源 SDK（GitHub windsor-ai/RedditAdsWindsorApi、windsoraiR，PyPI 包）引导开发者到 onboard 拿 API key。

推测:

  • Looker Studio（原 Google Data Studio）合作连接器库和模板库是 2020–2023 年最重要的上游流量（巴西、印度用户多，符合 Looker Studio 用户画像），但本次未直接查到 Google 连接器库页面。
  • 引荐里的 hubspot.com、shopify.com 可能来自应用市场上架。
