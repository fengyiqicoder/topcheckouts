基本信息

  • 产品：免费开源桌面软件 Arnis（Rust，Apache 2.0），框选地图区域即生成 Minecraft Java/基岩版/Luanti 世界；付费在线版 MapSmith 在浏览器里生成，手机也能用，最大 500 km²。
  • 创始人：Louis Erbkamm（GitHub louis-e），业余时间个人维护（官网自述 "works on Arnis in his spare time"）。有 Discord、Instagram @arnisworlds、Buy Me a Coffee 打赏。
  • 定价：桌面版免费；MapSmith 单次付费，€3（≤0.2 km²）到 €50（500 km²），中间档 €5/€10/€15/€25（map2minecraft 竞品对比页整理，https://map2minecraft.com/compare ）。
  • 上线时间：GitHub 仓库创建于 2022-09-10；v1.0.0 Release 2024-08-16；arnismc.com 域名注册 2025-09-13（RDAP），Wayback 最早快照 2025-12-16；README 2025-10-24 起把 arnismc.com 写成"唯一官方网站"。
  • 流量（profile 档案）：美 17%、德 12%、法 7%；搜索 63% 但 90% 是品牌词，直接 28%，社交来自 YouTube、X、Facebook。

增长循环

有证据:

  • 首发与起飞在 GitHub + Hacker News：2024-12 GUI 版发布后一周内上 HN 首页，紧接着科技媒体（Hackaday、XDA、Tom's Hardware）报道，作者自己在 README 里确认"2024-12 获得更多关注"。
  • 产出带品牌：用户生成的城市世界本身就是可晒的内容，YouTube 教程/展示视频、CurseForge 世界存档都带 "Arnis" 名字，观众看完搜品牌名——profile 档案显示搜索 90% 是品牌词。
  • 仿冒站涌现（issue #224）反证品牌搜索量大，作者因此注册官网统一入口。

推测:

  • 第一批 1000 用户大概率来自 GitHub trending / HN / Reddit Minecraft 和 OSM 社区（OSM Wiki 有专页），未查到 Reddit 首发帖原文。
  • MapSmith 变现靠官网+README 把"想要更大地图或手机用"的免费用户导流到付费版，付费转化率未知。

收入与规模线索

  • GitHub 18.4k 星；Release 下载累计约 93.9 万次（只算 GitHub 直链，不含官网分发）。
  • MapSmith 单笔 €3–€50，无公开营收数据；一人业余运营，另有 Buy Me a Coffee 和 GitHub Sponsors。

可信度与缺口

  • 起飞时间和来源（2024-12 HN + 媒体）证据充分，来自 GitHub API、HN API、README 原文。
  • 缺口：没找到作者访谈或 Reddit 首发帖；MapSmith 确切上线日期没查到（Wayback 本轮限流不可用），只能从 2026-03 付费投诉 issue 反推"最晚 2026-03"；营收无数据。
  • 搜索结果大多不相关（"launch"/"review" 查询返回的是 SQL 工具、药膏等），主要靠 GitHub/HN/RDAP 补证据。
