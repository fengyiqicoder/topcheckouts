第一批用户从哪来：有证据的是作者先做的 YouTube 演示频道（About 页明确"2014 年以 YouTube 频道形式创立，2015 年才有新闻页"）。之后的读者主要来自新品名搜索和同类站引荐（档案数据）。

增长循环

有证据:

  • 每日新品新闻 → 新品名长尾搜索（非品牌搜索 29%）。
  • 同圈子站互链：rekkerd、KVR、Elektronauts 合计约 13% 引荐流量。
  • YouTube 演示视频与文章互相嵌入，Facebook / X / subreddit 同步分发。
  • 联盟按钮 + 厂商广告 + 抽奖，厂商发新品时主动送稿和奖品。

推测:

  • 厂商把 Synth Anatomy 的长演示视频当作新品的"听感参考"，新品发布季（NAMM、Superbooth）带来流量高峰。

收入与规模线索

  • 收入未披露；联盟、广告、读者支持三条线。
  • 规模：YouTube 3.75 万订阅、1,000 万+播放；Facebook 2.9 万粉；X 6,600 粉。

可信度与缺口

  • 新站从零写。创立方式（先 YouTube 后网站）、时间点、所在地来自官网 About、RDAP、Wayback CDX、YouTube 和 X 资料，可信度高。
  • 缺口：作者全名未查到；Support 页（是否 Patreon）本次未读到，沿用档案说法；Google 搜索后三组结果基本无关（测速站等）。
