基本信息

  • 产品：macOS 剪贴板历史管理器，⇧⌘C 呼出、输入即搜、回车粘贴；支持忽略密码管理器内容、本地存储。
  • 价格：开源免费（GitHub releases、`brew install maccy`）；Mac App Store 版 $9.99，描述写"This version is being sold on the App Store to support the development"（https://apps.apple.com/us/app/maccy/id1527619437?mt=12，商店卖家显示 Antonina Ivanova，版权"© 2017 Alexey Rodionov"）。
  • 作者：Alex Rodionov（GitHub p0deje，所在 SF Bay Area，公司 Airbnb，简介"Alumnium | Bazel | Maccy | Selenium"，891 关注者）（https://api.github.com/users/p0deje）。
  • 规模：GitHub 22,058 星、1,247 fork（2026-10）；Homebrew cask 安装 30 天 8,606、90 天 25,134、365 天 110,988（https://formulae.brew.sh/api/cask/maccy.json）。
  • 域名：maccy.app RDAP 注册于 2019-08-06；Wayback 首抓 2019-08-22。GitHub 仓库创建于 2018-01-31（v0.1.0 同日）。
  • 流量画像（profile 档案）：美 15%、印度 12%、中国 11%；搜索 68.6%（品牌词 92%：maccy、maccy for mac、maccy download）；引荐 apple.com 4.8%；社交 YouTube、X、Reddit。

第一批用户从哪来：有证据的是 GitHub 开源（2018 年头半年 58 星，多为开发者）和 Homebrew 分发；2019-06 到 2020-06 的 6 倍增长期具体来源未查到。官网推荐语来自科普作者 Jatan Mehta、博客 The Sweet Bits、开发者 @lowercasename 等，说明有一批博客/推特口碑（具体日期未查到）。

增长循环

有证据:

  • 开源 + Homebrew：`brew install maccy` 一年 11 万次安装，开发者圈子里口口相传。
  • "一件事"定位：官网和 App Store 都强调"No fluff"，便于在"最佳剪贴板管理器/Ditto 的 Mac 替代"清单里被推荐（App Store 评论"If you used Ditto on Windows, this is the app for you on Mac"）。
  • App Store 引流：profile 显示 apple.com 引荐 4.8%，付费版本身也是一个发现入口。
  • 口碑强到被仿冒：2025–2026 年出现仿冒站和木马。

推测:

  • 2019 年下半年做官网后，可能在 Hacker News / r/macapps / Product Hunt 有过一次推荐（这是开源 Mac 小工具常见的起飞路径），但这次没能用工具查证，起飞方式记"未查到"。
  • 中国、印度用户占比高，可能与中文/印度开发者圈的"Mac 必装软件"清单和视频有关（profile 社交来源有 YouTube）。

收入与规模线索

  • 收入只有 App Store $9.99 赞助版；无公开销量。作者有 Airbnb 全职，Maccy 是副业。
  • 规模：2.2 万 GitHub 星、Homebrew 年安装 11 万，实际用户数应在数十万量级（推测，未核实）。

可信度与缺口

  • 新站从零写。仓库创建、官网上线、星标年度曲线、Homebrew 安装量、App Store 价格都有原始数据，可信度高。
  • 缺口：起飞事件（2019-06 至 2020-06）的具体渠道未查到；App Store 上架日期未核实；Reddit/HN 帖子在搜索结果里没有出现（reddit/review/tiktok 三组搜索结果为空）。
