有证据:

  • 第一批用户 = 作者自己的 X 粉丝：首发推 35 万浏览，后续每条干货/爆款拆解推文都挂预售链接；社交来源只有 X。
  • 阶梯涨价 + "已售 N 份"计数器制造紧迫感；买家在 X 上晒单、作者转发感谢，形成小范围社交证明。
  • 证言来自作者 X 圈子里的独立开发者（Postiz、Once 创始人等）。

推测:

  • 课程本身就是 SuperX 的内容营销：学员学 X 增长 → 可能顺带买 SuperX；反过来 SuperX 用户也是课程潜在买家。
  • 承诺的"社群"可能是后续复购/续费抓手。
