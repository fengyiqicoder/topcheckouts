增长循环

有证据:

  • Discord 为核心：官网客服走 Discord 工单，Telegram 首帖就是"唯一官方频道"并导向 Discord；Similarweb 社交来源只有 YouTube 和 Discord。
  • 批发 API + 加载器：给转卖商和工具用户开 API，把下游转卖网站/机器人变成分销渠道（批发商的复购表现为直接访问）。
  • 低价 + 即时发货 + 换号保障，复购率高，直接访问 89%。

推测:

  • "已有圈子迁移"：Discord 邀请码 archievable 和 GitHub 名 fakearchie 一致，推测运营者此前已在 CS2/Rust 账号或作弊圈子里有 Discord 社群，新站上线后把老客迁过来；没有找到首发帖。
  • YouTube 流量可能来自 CS2/Rust"便宜小号""开挂换号"类视频的描述区链接。
  • 波兰、阿塞拜疆、土耳其占比高，可能是这些地区的转卖商/网吧玩家集中使用。

可信度与缺口

  • 新站，从零写。产品规则、API、Wayback、GitHub 时间都是一手证据；起飞路径（Discord 迁移）是推测。

  • 缺口：运营者身份、Discord 规模、真实订单量和收入。
