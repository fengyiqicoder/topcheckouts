增长循环

  • 有证据:
    • 抢首发心智：OpenClaw 定名当天注册域名，6 天后发付费新闻稿，自称"world's first"。
    • 付费搜索买大词：品牌词 0%，付费搜索 55.3%，自然搜索 38.6%。
    • SEO 教程页：从 2026-01-31 起持续发 OpenClaw 教程、对比页、Skills 页。
    • GitHub 技能合集仓库引流：openclaw-master-skills 2.2k 星，另有 guardian、backup、bench 等仓库，都挂 "Powered by MyClaw.ai"。
    • YouTube 创作者教程和评测，Medium/Substack 软文，形式符合付费合作。
    • 联盟渠道：引荐来源里有 impact.com，占 3.8%。
  • 推测:
    • YouTube 和 Medium 评测大概率是付费或联盟合作。
    • 没有用户拉用户的产品内循环，流量跟着 OpenClaw/Hermes 的热度起落，本质是"依附上游流量 + 买量"。
    • Trustpilot 口碑差，说明留存一般，要靠持续买量补新客。
