Curic（"curic4su" = Curic for SketchUp）是一个小型 SketchUp 插件工作室，至少从 2016 年起陆续做"补 SketchUp 原生短板"的小工具（Face Array、Section、DIO 画线、Offset/Intersect、Extend、Stretch、Hidden、MiniMap、Outer Shell 等），每出一个就到 SketchUp 官方论坛、X、YouTube、Facebook 发演示视频，靠 SketchUp 生态的论坛和插件名搜索获客，Gumroad 收款，免费插件引流、付费插件和打包的 Curic Studio 变现。2023 年从 curic4su.com 换到 curic.io；旧域名失效后被劫持挂恶意 PowerShell 命令（2026-09 论坛曝光），新站 上个月流量环比 +914%，推测与老用户被迫迁到新域名有关。一句话发家逻辑，由我们根据公开资料整理；推测部分在下文单独标出。

增长循环

有证据:

  • 每个新插件在 SketchUp 官方论坛单独发帖（Related topics 里有一串 Curic 插件发布帖），配演示视频。
  • 免费插件区（Free Extensions）作为引流，付费插件和 Curic Studio 在 Gumroad 收款，节日折扣。
  • 插件名搜索：品牌词 85%，搜索词多是"curic + 插件名"。

推测:

  • 巴西、日本、印度建筑/室内设计 SketchUp 用户多，靠 YouTube 教程博主自发推荐传播（推测）。
  • 上个月暴涨很可能是旧域名失效、插件内链接和老用户转向 curic.io 所致，非真实新增。
