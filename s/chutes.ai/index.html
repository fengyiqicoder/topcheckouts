基本信息

  • 产品：Serverless 开源模型推理 API（OpenAI 兼容），支持任意部署"chute"，现在主打 TEE（可信执行环境）隐私推理；订阅 Plus $10/月（2,000 次/天）、Pro $20/月（5,000 次/天），另有按量计费（如 DeepSeek V4 Flash $0.44/$1.32 每百万 token）。还做去中心化训练（2026-09 用 13 国 240 张消费级 GPU、花 $6,500 训练了一个 8B 模型）。
  • 公司：Chutes Global Corp（官网页脚）；团队约 8 人，核心后端 Jon Durbin（开源模型 Airoboros 作者），其余多用网名。最初出自 Rayon Labs（Bittensor 子网团队，GitHub 组织 2024-09 建立）。有专职增长负责人 Burhan Khan（LinkedIn 职位"Head of GTM and Growth"）。Reddit 社区由 Mikesoft（@thestreamcode）运营。
  • 融资：未查到传统 VC 融资；收入和补贴依赖 Bittensor 子网排放（dTAO 后子网有自己的 alpha 代币）。
  • 国家：美国为主（我方数据美国占 55%）。

增长循环

  • 有证据:
    • 上游分发：OpenRouter 把 Chutes 作为提供商路由；Kilo 等编程 Agent 工具把它列为合作后端；taostats.io（Bittensor 生态）是主要引荐来源。
    • 免费额度拉新：每日约 200 次免费 DeepSeek，在 SillyTavern、Cursor 论坛等社区口口相传（"Chutes offers deepseek for free"）。
    • 社区运营：官方 Reddit 社区有专人运营，社区成员自己做插件把 Chutes 接进编程工具；Bittensor/加密圈是基本盘（官方原话）。
    • 2026-05 起投 Reddit 广告，属于花钱买量。
  • 推测:代币补贴形成"价格低→流量大→子网排放多→更能补贴"的飞轮；角色扮演圈的 Discord 和 TikTok 教程（"用 Chutes API key 白嫖 DeepSeek"）扩散，来自 JanitorAI 等应用的流量属凭记忆，未核实。上两个月收款页猛增可能对应 DeepSeek V4 等新模型上线（2026-08-25 官方推 V4 Flash 定价）。

收入与规模线索

  • 定价：Plus $10、Pro $20/月，加按量付费。
  • 规模：2025-06 月超 3 万亿 token；到 2026-09 累计 34 万亿，日峰值 1,200 亿。
  • 2026-03 官方称砍量后每 token 收入 +37.7%（绝对收入未公开）。

可信度与缺口

  • 上线时间（2025-01 下旬）、2025 年上半年 250 倍增长、2025-08 开始收费、2026 年两条 X 官方帖都有来源（X 帖只有摘要）。
  • 二次补查：补上了公开上线时间（2025-01 下旬，与 DeepSeek R1 同期）、第一批用户来源（免费 DeepSeek 额度在 SillyTavern 和 Cursor 等社区传播，2025-04 SillyTavern 已有专帖）、token 规模的时间线，以及 2026 年转向"砍低价值 token + Reddit 广告买量"。"OpenRouter 免费端点吸走角色扮演用户"仍属凭记忆，未找到原始链接。
