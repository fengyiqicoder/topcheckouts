基本信息

  • 产品：Crash Bash Online，非官方浏览器移植（官网强调"不是模拟器、不是 ROM"），支持单人打 CPU、2–4 人公开/私人房间、键盘/手柄/触屏；目前 28 个竞技场（原作 29 个），7 个小游戏系列。
  • 开发者：Paolo Furlan（个人，隐私政策写明"run by Paolo Furlan, an individual"；阿根廷媒体称其为英国个人），同一开发者还有 iOS 游戏 Bitcoin Factory（App ID 1359240181，2018 年左右上架的放置挖矿游戏）和 Wall Street Raider（股票模拟，App ID 6759681029）。小团队/个人，无融资信息。
  • 托管：Cloudflare；分析：Google Analytics；社区：Discord（discord.gg/tb8GECFFWW）、X、Instagram、TikTok。
  • 上线时间：Wayback 最早快照 2026-09-20；官网 Updates 最早一条 2026-09-19（按键重映射、每系列前两个竞技场）；首篇媒体报道 2026-09-21。.app 注册日期 WHOIS 未查到（返回的 2015 为注册局日期）。
  • 变现：Retro Dodo（9-21）称计划推出"Arena Pass"（付费解锁剩余竞技场、私人房间、去广告，观战/加入免费），当时页面有广告；意大利 Everyeye（9-28）称"靠广告和可选捐赠"。但 2026-10-06 版隐私政策写"不展示任何广告"，/pass 页面现已 404——说明变现方式在 本月初改过（可能是怕版权方，属推测）。

增长循环

有证据:

  • 多人房间：PRIVATE BATTLE 由房主建房并"share a code"，好友用 BATTLE BY CODE 加入；空位 CPU 自动补齐，所以一个人分享链接就能立刻开局（官网）。
  • 零门槛：浏览器、免下载、手机触屏可玩，媒体标题反复强调"free in your browser"，适合被转发。
  • 怀旧 IP + 媒体链：Retro Dodo → Everyeye（意）→ Cultura Geek（阿）多语言转载；服务器区域在一周内从欧洲扩到 6 区再拆亚洲、加南美，佐证流量全球化。
  • Discord 承载公开房间帖子（隐私政策提到"Discord carries the public room posts"）。

推测:

  • 上个月"付费页访问≈29547"可能来自 Arena Pass 的结账页或捐赠页；后期撤掉广告/Pass 页。
  • X/TikTok 上的对战片段带来社交流量（社交来源前三为 X/Facebook/YouTube，具体爆款帖未查到）。
  • 上 4–6 个月均值 404 的付费页访问，域名之前用途未查到（Wayback 无 上个月前快照）。

收入与规模线索

  • 无公开收入/用户数。间接规模：一周内开 6 个区域服务器 + 东亚/东南亚拆分 + 南美服，说明并发玩家遍布全球。
  • 定价：Arena Pass 曾计划收费（价格未公开），现页面 404；隐私政策称无广告。

可信度与缺口

  • 开发者身份、上线日期（2026-09-19/20）、媒体时间线可信度高（官网 updates + 多家媒体）。
  • 缺口：首发帖位置、实际 MAU、Arena Pass 是否真的卖过/价格、为何撤掉广告；版权风险高（非官方使用 Sony/Activision IP），存活期不确定。
