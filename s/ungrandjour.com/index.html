基本信息

  • 产品：法语为主（另有英、德、西、意语界面）的婚礼一站式平台：婚礼网站、礼物清单、份子钱（cagnotte）、RSVP 问卷、二维码生成器；也支持出生、生日、退休活动。
  • 收费："On se finance avec une commission de 3% + 1€ sur la cagnotte, tout le reste est inclus 100% gratuitement"（https://www.ungrandjour.com/fr）；英文页称份子钱资金有最高 10 万欧保障（https://www.ungrandjour.com/en/wedding-cash-fund）。收款走 Stripe Connect，新人需在 Stripe 做实名认证（CGV）。
  • 公司：Un Grand Jour SAS，注册资本 1,000 欧，CGV 写地址在 Bondues（里尔附近）；法国企业登记 API 显示 2022-05-03 成立、现注册地址巴黎 8 区、NAF 62.01Z（软件开发）、登记的总经理 Georges Vernier（https://help.ungrandjour.com/legal/cgv ；recherche-entreprises.api.gouv.fr，SIREN 913113460）。
  • 关联：Memorable（memorable.me）"créée en 2026 par le fondateur de ungrandjour.com"，运营主体 Memorable Day SAS。
  • 域名：ungrandjour.com RDAP 注册于 2021-11-05，ungrandjour.fr 同日注册；.fr 先上线（2021-12 至 2022-04 快照），2023 年起 .fr 301 跳到 .com。
  • 流量画像（profile 档案）：法国 80%、比利时 6%、德国 4%；直接 72.8%、搜索 27.2%（品牌词 89%）；社交来自 Facebook Messenger；有出生贺词类内容搜索词；季节性明显（8 月 410 → 9 月 4,500）。

增长循环

有证据:

  • 产出带品牌：每个婚礼页面、份子钱页面和 RSVP 链接都在 ungrandjour.com 域名下，由新人发给宾客（profile 显示社交来源 Facebook Messenger、直接访问 72.8%）。
  • 免费 + 只抽份子钱：除 3% + 1 欧外全部免费，降低新人试用门槛。
  • 评价运营：主动邀请评价，Trustpilot 4.8 分、4,800+ 条，首页挂 Trustpilot 组件。
  • 内容长尾：博客婚礼/出生/生日指南和贺词模板（"modèle texte"）；profile 显示出生贺词等内容词带来搜索。
  • 婚礼博客合作：La Mariée en Colère 介绍文（疑似合作）。

推测:

  • 宾客 → 未来新人的转化是核心循环：婚礼宾客里有大量即将结婚的同龄人。
  • 多语言界面（德、西、意）说明在试欧洲其他市场，但目前流量 80% 在法国。

收入与规模线索

  • 收入 = 份子钱流水 × 3% + 每笔 1 欧。无公开流水数据；企业登记 API 未返回财务数据。
  • Trustpilot 近 12 个月 4,000+ 条评价，如果评价率在 10%–30%，对应每年几千到一万多场活动（推测）。

可信度与缺口

  • 新站从零写。域名/公司成立时间、收费方式、Trustpilot 数据、Memorable 关系有原始证据。
  • 缺口：创始人身份（登记的总经理 Georges Vernier 是否为创始人未核实，总裁为法人股东）；首批用户来源和起飞事件未查到；"搜索长尾"是按博客和 profile 推断的起飞方式，证据弱。Pappers 页面 403，未拿到财务数据。搜索结果"launch / reddit / review"组几乎全是无关词典页。
