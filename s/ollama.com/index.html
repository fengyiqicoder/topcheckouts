基本信息

  • 产品：开源的本地大模型运行器（CLI + 本地 API + 2025-07 起的桌面 App），外加 Ollama Cloud 云端模型订阅（Free / Pro $20/月或 $200/年 / Max $100/月 / Team）。
  • 团队：Jeffrey Morgan（CEO）与 Michael Chiang，此前做 Kitematic（2015 年被 Docker 收购）。公司在美国 Palo Alto。
  • 融资：YC W21（金额各聚合站说法不一，约 $12.5 万）；2026-07-09 由 Theory Ventures 领投 $6,500 万 B 轮（Benchmark、8VC、YC 等跟投），累计 $8,800 万。
  • 首个版本：GitHub v0.0.1，2023-07-08（https://github.com/ollama/ollama/releases/tag/v0.0.1 ，Wikipedia 引用）。
  • 域名 WHOIS 注册于 2017-05-08（远早于产品，可能是买来的老域名）。

增长循环

  • 有证据:
    • 第一批用户：Simon Willison 博文（2023-07-18）+ Replicate 官方教程（07-22），都和 Llama 2 发布同周，读者是 Mac 上的开发者。
    • 开源 + 集成生态：官方 Docker 镜像、OpenAI 兼容 API、Python/JS 库、Firebase Genkit、Obsidian、IDE 插件，6.7 万+第三方集成把 Ollama 当默认本地后端，用户装别的工具时被要求先装 Ollama。
    • 模型首发上架：官方博客里几乎每次大模型发布（Code Llama、Llama 3、Gemma 2、gpt-oss、Qwen3-VL、MiniMax M2…）都有当天上架文。
    • Agent 浪潮：2026 年初接入 Claude Code、Codex、OpenClaw，把用户从"本地聊天"带到"本地/云端跑 coding agent"。
  • 推测:
    • 新模型发布 = 流量脉冲：教程和视频作者自发产出 `ollama run xxx` 内容，搜索"本地部署 XX"落到 ollama.com。
    • 付费转化：本地跑不动的大模型引导到 Cloud 订阅，CLI 习惯不变，免费用户直接转付费。
