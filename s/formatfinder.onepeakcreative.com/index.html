  • 域名：onepeakcreative.com 的 Wayback 最早快照是 2021-12-08；formatfinder 子域最早是 2026-03-31。RDAP 查询失败。

增长循环

有证据:

  • 课程漏斗导流：每周免费直播大师课 → 课程/教练 → Format Finder 订阅，Peak 档把课程打包进订阅。
  • 学员案例当社会证明："Mary Beth 一条视频 2,000 万+播放"、Betsy、Kaitlyn 百万播放案例页。
  • SEO 资源库：2026-10 起成体系上线 how-to、对比页（format-finder-vs-chatgpt）、术语页；渠道档案里搜索占 35.9%。
  • 广告：有 Trustpilot 评论提到"adverts"；母公司卖 Meta 广告课，投放能力强。

推测:

  • 直接流量占 52%，说明主要靠老学员邮件列表和登录回访，不靠病毒传播。
  • 用户产出的视频不带品牌，产品本身没有传播环。

  • 母品牌自称 161,453 名学员/创作者（累计课程用户，不是 Format Finder 付费用户）。

  • 首页挂 Amazon、Downy、Expedia、Marriott 等企业培训客户 logo。

可信度与缺口

  • 从零新写（之前没有旧报告）。搜索结果几乎全是无关内容，证据主要来自官网、母公司官网、Wayback、App Store 和 Trustpilot。
