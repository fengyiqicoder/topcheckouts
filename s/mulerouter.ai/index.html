基本信息

  • 产品：多模态 + LLM API 网关（"World's FIRST Skills-Native AIO API platform"），统一鉴权调用 Wan、Qwen、GPT、Nano Banana、Kling、MiniMax、Grok、GLM 等；自有"Spark"系列是 Wan 视频模型的低价微调版；提供 npm CLI `mulerouter` 和给 Claude Code 用的 Agent Skill。
  • 谁做的：官网页脚只写"© 2025 MuleRouter"，未署公司。关联证据：GitHub "Get Started" 指向 openmule 组织（该组织 blog 字段是 mulerun.com，2025-06-16 创建），skills 仓库同时支持 MuleRouter 和 MuleRun 两个网关、共用 MULEROUTER_API_KEY 变量。MuleRun 是阿里云副总裁陈宇森（长亭科技联合创始人）领头的阿里云内部创业项目——来源 https://ai.miraheze.org/wiki/MuleRun 。所以 MuleRouter 大概率是 MuleRun/阿里云团队的 API 产品（推测，官方未明说）。
  • 定价：按量计费，官网未公开价格，定价页 404。
  • 域名：mulerouter.ai 注册于 2025-11-04（RDAP），2026-01-13 发生过注册商转移；Wayback 首个快照 2025-12-11（当时首页主打 Qwen3 Max、Wan 2.5 预览、Nano Banana Pro）。
  • 流量（profile 档案）：美国 37%、印尼 12.8%、印度 11.9%；引荐 47%、直接 39.8%、AI 助手 8%；搜索词含"mulerouter pricing""wan2.5-i2i-preview"。

第一批用户从哪来：没有找到首发帖或公告。可查到的线索是：（1）首页一直把阿里最新 Wan/Qwen 预览模型放在最显眼位置，搜索词里有具体模型名"wan2.5-i2i-preview"，说明一部分开发者是按新模型名找来调用的；（2）引荐流量占 47%，结合 skills 仓库同时服务 MuleRun，推测引荐主要来自 MuleRun 生态和阿里系模型文档/合作页（推测，引荐站点名未拿到）。

增长循环

有证据:

  • 抢新模型窗口：每有热门模型（Nano Banana Pro、Wan 2.5/2.6/3.0、GPT Image 2）就上架并在首页打"New"，每个模型都有独立落地页（sitemap 60+ 个 /models/ 页）。
  • Agent 生态接入：Claude Code 插件市场一条命令安装，npm CLI。

推测:

  • 依托 MuleRun（60 万+注册）和阿里云的流量/客户关系做导流，所以引荐占比高。
  • 以 Wan/Qwen 的低价（含自家 Spark 微调版）吸引对成本敏感的印尼、印度开发者。

收入与规模线索

  • 无公开价格和用户数；Discord 193 人、skills 仓库 19 星，社区规模很小。
  • 主要价值可能在于给阿里模型做海外分发，而非独立盈利（推测）。

可信度与缺口

  • 新站从零写。搜索结果几乎全是无关页面（测速站、OpenRouter 评测），只能靠官网、GitHub API、Discord API、Wayback、RDAP 和 MuleRun 的 wiki 补证据。
  • MuleRouter 与 MuleRun/阿里云的关系是根据同一 GitHub 组织和共用 skills 推断的，官方未明说。
  • 缺口：运营公司主体、定价、引荐来源站点、用户量都未查到。
