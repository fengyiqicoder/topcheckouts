基本信息

  • 产品：AI Agent 用的云 VM/沙箱：完整 Debian + systemd、硬件虚拟化、约 500ms 启动、400ms 内横向 fork 整个内存状态、休眠/快照恢复、网络规则、最高 64GB 内存；此前的网站部署 API 和 JS 沙箱仍在。
  • 团队：Benjamin Swerdlow（CEO，高中时做过 WHO COVID-19 App Collective 技术负责人，离开 Apple 咨询岗创业）、Jacob Zwang（CTO，19 岁辍学进 Apple 做高级全栈工程师）；YC S24，合伙人 Diana Hu，5 人，旧金山——来源 https://www.ycombinator.com/companies/freestyle
  • 定价：免费 $0；Hobby $50/月+用量；Pro $500/月+用量；YC 创业者送 $5 万额度（校友 $2.5 万）+ 6 个月 Pro——https://www.freestyle.sh/yc
  • 域名：freestyle.sh 无 RDAP 数据（.sh 注册局）；Wayback 首个快照 2024-04-17；早期文档和博客在 freestyle.dev。
  • 流量：美国 30%、印度 27%、印尼 19%；直接 64%、搜索 27%（品牌词 91%）、社交 5.4%（X、YouTube）。

第一批用户从哪来：YC S24 同批和校友圈（YC 专属额度页），以及 2025 年 AI 建站器公司——Onlook、a0.dev 等是 B2B 早期客户，官网直接引用它们的话做背书。具体首批用户数未查到。

增长循环

有证据:

  • 客户的产品就是分发：AI app builder 每替终端用户部署一个网站，就跑在 Freestyle 上（a0.dev 3,000+ 域名、Onlook 每天数百次部署）。
  • 开源模板引流：开源 adorable app builder 模板和 cloudstate 运行时，开发者 fork 后默认用 Freestyle 部署。
  • YC 网络：YC 创业者 $5 万额度、校友 $2.5 万。
  • Hacker News Launch（322 分）+ 开发者 meetup + 创始人 X 观点输出。

推测:

  • 印度、印尼流量高，可能来自用开源 app builder 模板的个人开发者。
  • 被竞品/开源项目拿来对标（Agentjail）进一步强化"Agent 沙箱"品类认知。

收入与规模线索

  • 定价 Hobby $50/月、Pro $500/月 + 用量；客户以 AI 建站和编程 Agent 公司为主。
  • 自建裸金属机房，说明用量已到一定规模（Launch HN 自述）；营收、融资额未查到（YC 标准投资，凭记忆，未核实）。

可信度与缺口

  • 新站从零写。产品三次转型有 Wayback 快照逐段证据，Launch HN 和 YC 页面是一手来源。
  • 搜索结果的 launch/review 查询多为无关页面和 CVE 页，只用了 HN 和 YC 优惠页链接。
  • 缺口：GitHub 星数（API 限流未读到）、Onlook 等客户合作是怎么谈成的、付费客户数和营收未查到。
