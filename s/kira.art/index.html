基本信息

  • 产品：模板式 AI 图片和视频生成加社区。自研或封装了 Lite / Nova / Ultra 三档模型，功能有动作控制（照片跳舞）、视频编辑和延长、音乐生成，还有大量一键模板（"Sun-Kissed Tan""3D Disney 头像""You in GTA 5"）。有 Gallery、Timeline 社区、@提及和用户名（5.9 版），有 Discord。
  • 定价：免费注册送 50 积分；有 Pro / Max 订阅（视频生成在 Pro 以上），具体价格没查到；邀请一人送 50 积分。
  • 团队：ILLA Cloud 孵化；页面提到的成员有陈龙博（前快手孵化业务大前端负责人）、吴晓松（前抖音主业务线设计）；开发者主体是北京艾拉云科科技有限公司（来源：攻壳智能体）。第三方页面称"Singapore app"。
  • 域名：kira.art 于 2025-06-04 注册（RDAP），Wayback 最早快照 2025-06-26（"AI AGENT FOR CREATIVITY"，修图功能列表）。
  • 用户：美国 17%、巴西 10%、韩国 8.5%；直接流量 67%，品牌词 92%（渠道档案）。

增长循环

有证据:

  • 付费 UGC 矩阵：按条付现金让素人发 TikTok 钩子视频，播放越高付得越多，要求在评论里放活动链接、带 #kiraart。这本质上是花钱买量，但投在素人内容上。
  • 话题挑战用积分做奖励（最高一个月免费 Pro），平台覆盖 TikTok、Instagram、X。
  • 邀请一人送 50 积分（渠道档案里新客来源记为病毒传播）。
  • 产出天然可分享："把朋友做成内容"，朋友被做进视频后会转发；站内社区加话题标签让作品沉淀。
  • Product Hunt 发布三次，用于版本节点曝光。

推测:

  • 韩国、巴西流量占比高，和 K-pop 舞蹈、足球模板的本地化选题有关。
  • 引荐来自 thefappeningblog、dcinside 等站，说明有擦边或社区自发传播。

收入与规模线索

  • 价格没查到；Product Hunt 1.6K 关注。
  • 付费创作者计划单条最高 $200，说明有持续的营销预算，背后有 ILLA Cloud 的融资（凭记忆 ILLA Cloud 拿过红杉中国等的融资，未核实）。
  • 安全评分站给 34/100，并提到有厂商把它列入黑名单，可能和投放落地页有关。

可信度与缺口

  • 从零新写（之前没有旧报告）。产品转型和投放机制的证据较硬（Wayback、Product Hunt、creator 页面）。
  • 缺口：用户量、收入、付费价格，以及 2026-03 之后的增长曲线都没有原始数据；2025-12 的快照显示为"AI Photo editor / Photoshop 替代，即将上线"，可能是试过的另一个方向，未核实。
