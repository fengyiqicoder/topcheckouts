增长循环

有证据:

  • 搜索占位：我方渠道数据搜索占 49.2%，搜索词就是通用大词 youtube transcript / generator 和法语长尾；精确匹配域名 + 11 语种 hreflang + 一批"youtube transcript xxx"长尾落地页（sitemap 可见）。
  • AI 助手引荐 7.6%（我方数据），网站专门做了 MCP 服务和 API 页，About 页说 MCP 已进官方 registry。
  • 网站 → 插件导流：首页和 FAQ 推 SubKun Chrome 插件，链接带 utm_source=youtube-transcript&utm_campaign=hero，插件 7,000 用户。
  • 偶发博主自发推荐：埃塞俄比亚博主视频带来 229 次会话（团队博客自述）。
  • 搜索结果显示这个赛道极度拥挤（yttranscript.ai、transcriptmagic、notegpt、smry、wave.co 等几十家同类免费工具），没有看到任何首发帖、Product Hunt、Reddit 推广帖。

推测:

  • 第一批用户大概率直接来自 Google/Bing 对"youtube transcript"的搜索：精确匹配 .ai 域名 + 免费不注册，上线几个月后开始有排名。没有直接证据。
  • 直接访问 38.1% 很高，推测是学生、创作者反复回来用（收藏夹）以及插件跳转。
  • r/YouTubeTranscript 是团队自建的子版块（页脚链接），可能是想占 Reddit 搜索结果，规模未查到（Reddit 打不开）。

收入与规模线索

  • 网站本身免费；收入来自 SubKun Pro 订阅和 API，金额未查到。
  • SubKun 插件 7,000 用户、298 条评分（2026-08）。About 页称"1,818 条真实用户评价，4.7/5"。
  • 博主带来的 4 天 229 次会话被当成值得写博客的事件，说明 2026 年站点整体流量还是小体量（推测）。

可信度与缺口

  • 上线时间（注册 2025-07、首抓 2025-10）、同团队关系、插件开发者信息、我方渠道数据都有一手来源，可信。
  • 给的搜索结果几乎全是同类竞品，没有任何关于这个站的报道、访谈、首发帖；增长路径主要靠官网、sitemap、RDAP、Chrome 商店和我方渠道数据推断。
  • 缺口：创始人是否就是 XiaoLong Zhang（只能确认他是 SubKun 插件开发者）、第一批用户的具体来源、营收、r/YouTubeTranscript 规模（Reddit 和 Wayback 正文都打不开）。
