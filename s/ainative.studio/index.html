基本信息

  • 产品：OpenAI 兼容 API，接入 65+ 开源模型（Kimi K3 输入 $0.28/M、GLM-4.6、MiniMax M2、DeepSeek V3.2），另有 ZeroDB 持久记忆、69+ MCP 工具、Cody CLI、AI Kit（React 组件）、Agent Cloud，以及最新的 Intent-Casting Marketplace（基于 Beckn 协议）。另开了子站 builder.ainative.studio，卖"AI 联合创始人"。

  • 谁做的：Toby Morning，创始人兼 CEO。他是 Bill Gross 旗下 Idealab 孵化的 IdeaMarket 的一号员工，2023 年春在 Techstars Tulsa 当导师。团队里还有 Karsten Wade（开发者关系负责人，title 是"Head of Vibe Coding"）；"CTO Cody Jackson"其实是 AI Agent。公司主体 AI Native Lab Inc，Santa Cruz Works 报道说在 Santa Cruz，LinkedIn 写的是旧金山加塔尔萨。融资：一直自筹，2026-06 开始第一轮融资，已开投资人 deal room。
  • 上线时间：GitHub 组织创建于 2025-05-31；Santa Cruz Works 说"2025 年 9 月起开始做 AI 基础设施"，可以理解为 2025-09 转向 API 和记忆平台。

增长循环

  • 有证据:
    • 线下活动：创业营、黑客松、Speakeasy 活动，Cody 在黑客松上发贴纸。
    • 社区：Discord、WhatsApp 群、LinkedIn newsletter、AINative Live。
    • 开源仓库引流：几百个公开仓库，比如 ainative-openai、ainative-openai-python 打"免费开源模型 + OpenAI 直接替换"。
    • 第三方 AI 工具目录收录，比如 withai.top。
    • 渠道数据：直接访问 62.5%，搜索 28.1%，其中九成是品牌词（"ainative studio api key"），展示广告 5.6%。
  • 推测:
    • 用户集中在印度、孟加拉、尼泊尔，说明低价开源模型 API 在南亚开发者圈里有口碑。可能来自"免费/便宜 Kimi、GLM API"这类白嫖资源帖或 YouTube 教程，但没找到具体帖子。
    • 展示广告可能是小规模投放。

收入与规模线索

  • 官网自称 5,600+ 开发者、99.9% 可用率。
  • 团队 2 人加 AI Agent，自筹资金，2026-06 才开始融资，收入规模应该很小。
  • 我方表中该站 8/9 月数字和 esim.gg、myclaw.ai 完全一样（4,919 / 21,490），疑似数据源分档估算，真实流量可能小得多。

可信度与缺口

  • 第一批用户从哪来、起飞事件仍未查到。搜索结果里没有 Reddit、HN、Product Hunt 首发帖，"viral"查询也没有相关结果。
  • 二次补查：确认 Toby Morning 是创始人兼 CEO（原为推测），补上 Techstars Tulsa 起源、自筹融资、Santa Cruz 报道、DevRel 成员和 2026 年活动；起飞年份从 2025 改为 2026（流量在 2026-09 才跳升）。
