增长循环

有证据:

  • 创始人即创作者：Sulan 用 Vyra 剪自己的 Reels，爆款视频本身就是产品演示，结尾引导评论领链接。
  • 付费 UGC：官网"Create for us"招募用户用自己的素材拍 Vyra 推广短视频并付费；创始人和推广者用 /go/<名字> 追踪链接。
  • SEO 落地页：sitemap 255 个 URL（/tools/tiktok-video-editor、/compare/vyra-vs-adobe-premiere、/alternatives 等），搜索流量占 41.8%。
  • 蹭 AI Agent 生态：MCP 接入 Claude/ChatGPT/Cursor，并有 /claude、/chatgpt、/cursor 落地页。
  • 第三方评测背书：Buffer 横评第一（自称）。

推测:

  • YC 背书 + X 上的 MCP 演示带来开发者/AI 圈的早期尝鲜用户。
  • "Made with Vyra"作品展示 + 用户发布的视频可能带来少量口碑，但导出视频本身是否带水印未查到。
