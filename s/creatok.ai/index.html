基本信息

  • 产品：给 TikTok Shop 卖家的 AI 视频工作台——拆解爆款带货视频脚本、套自家商品重做、生成图片/配音、通过 TikTok 官方 API 排期发布；附带去水印、去字幕、抠图、放大、翻译等小工具；Chrome 扩展（TikTok 脚本/商品分析）；2026 下半年出 Open API、CLI 和给 Claude Code/Codex/OpenClaw 用的 skills。
  • 谁做的：官网 About 只写"CreatOK"，无公司实体；Miraheze 维基称"巴塞罗那两位西班牙创业者，2025-10 上线"（来源不明，可能是自写词条，未核实）；Chrome 扩展开发者邮箱 dev@echosell.com（echosell.com 2022-07 注册，内容未抓到），扩展支持英文和简体中文，流量中国 27% 居首——团队背景存疑。
  • 上线时间：RDAP 注册 2025-07-22；Wayback 首次抓到 2025-10-26（首页 + 登录页）；2025-11-10 出现 /pricing、/sora-video-cloning、/sora-video-generation。
  • 官网自报：500K+ 用户、10M+ 视频、20+ 国家；"TikTok Official API Gold Service Partner"。
  • 定价：可免费开始，Pro 等订阅档（profile 档案，具体价格未查到）。
  • 流量（profile 档案）：中国 27%、泰国 14%、印尼 8%；直接 49.8%；品牌词 57.4%，约 30% 新客来自非品牌搜索（bg remover、remove subtitles from video online free、subtitle remover）；付费搜索 7.5%；社交只有 YouTube。

增长循环

有证据:

  • 免费工具页吃搜索：去字幕、去水印、抠图等页面多语言化（en/zh/zh-TW/ja），非品牌搜索约 30%（profile 档案 + Wayback）。
  • 追热点模型：Sora → Seedance 2 → Kling/Veo，每次都出评测/对比博客和对应落地页。
  • AI 工具目录站收录（aitools.fyi、aitoolly、startupaitools、saaspirate 等）。
  • 付费搜索 7.5%。

推测:

  • 卖家用 CreatOK 做的视频发到 TikTok 上不带明显品牌，产品本身难以自传播。
  • "500K+ 用户"大多是用免费小工具的人，付费卖家占比未知。

收入与规模线索

  • 官网自报 500K+ 用户、10M+ 生成视频、20+ 国家（2026-10）。
  • Chrome 扩展仅约 1,000 用户。
  • 收入、融资未查到。

可信度与缺口

  • 新站从零写。"launch""review""tiktok"三组搜索结果多为无关泛文；主要证据来自官网首页、Wayback CDX 页面首抓时间、RDAP、Chrome 商店页、Miraheze 维基。
