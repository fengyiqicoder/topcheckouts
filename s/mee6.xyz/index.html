  • 产品：Discord 服务器机器人 MEE6：管理/自动审核、等级与排行榜、自定义命令、欢迎消息、反应角色、Twitch/YouTube/Reddit 通知、工单等；后加 MEE6 AI（profile 档案、竞品博客）。
  • 定价（2026-08，按服务器）：Premium $11.99/月、$49.99/年、$89.99 终身；MEE6 AI 另收费（个人 $41.88~$119.88/年，服务器 $3.49/月起）；社交通知、更多自定义命令等都在付费墙后（vibebot 竞品博客）。
  • 谁做的：机器人登记的所有者 anis#0（bots.ondiscord.xyz），GitHub 仓库作者 cookkkie；公司在法国（凭记忆，未核实）。
  • 上线时间：RDAP 注册 2016-02-15；机器人账号 ID 159985870458322944，按 Discord 雪花 ID 换算创建于 2016-03-17；Wayback 最早 2016-03-22 首页"Mee6: the Discord bot! … Release your !power,!mana,!chakra,!skill for everyone in your server — Add to discord"，导航有 Github 和 Discord 社群链接。

第一批用户从哪来：Discord 早期开发者/管理员圈子。证据是：2016-03 首页直接放 GitHub 和 Discord 支持服链接、代码开源；仓库带 Carbonitex 上报组件，说明它挂在当时唯一的机器人榜单上被管理员发现（推测基于组件名）。具体首批服务器名单和数量没查到。

增长循环

有证据:

  • 装一次、全服可见：等级、欢迎、通知消息都以 MEE6 名义在服务器里发，成员看到后去搜品牌词（profile 档案：直接 75.6%、品牌词 97.5%，"新客来源：病毒传播"）。
  • 后台网页配置，降低门槛，"不用会编程就能加命令"（GitHub README）。
  • 主播/社群用 Twitch、YouTube 通知功能，twitch.tv 和 linktr.ee 带来引荐（profile 档案）。

推测:

  • 2016 年 Discord 处在爆发期、机器人很少，先占位的 MEE6 成了新服务器的默认安装项，教程视频和"必装机器人"清单再放大。
  • 后期把功能放进付费墙引起反感，竞品（Carl-bot、Dyno 等）靠"MEE6 替代品"拉走一部分用户。

收入与规模线索

  • Premium 按服务器收费：$11.99/月、$49.99/年、$89.99 终身；另有 MEE6 AI 订阅。
  • bots.ondiscord.xyz 单一渠道就有 84 万次邀请；官网称"millions of Discord servers"（搜索摘要），没有一手数字。
  • 收入数字未查到。
