增长循环

有证据:

  • 邀请返利：每个用户有 /invite/码，Wayback 抓到数十个不同邀请码，说明用户在各处贴邀请链接。
  • 开源项目赞助：CC Switch README 专属邀请码 + 首充 10% 奖励。
  • 训练营/社群合作送额度（彭涛训练营）。
  • 订阅每 4 周续费 + 额度 7 天刷新，老用户高频直接回访（直接访问 80.6%）。

推测:

  • 中转站之间竞争主要靠"稳定 + 不封号"的口碑，在中文开发者 Telegram/微信群里传播；Claude Code 对中国区的限制（2026-07 有"中国特供遥测"文章）反而加大了对中转的需求。

收入与规模线索

  • 官网自报 10,000+ 开发者用户；套餐 ¥399–1,799 / 4 周。若 10% 用户订阅 Pro，月收入约 ¥40 万（纯推测）。
  • 美国+香港流量占 74%，说明用户多在海外或走代理。

可信度与缺口

  • 新站从零写。搜索结果大多无关（第一组全是"health"）；主要证据来自 CC Switch 仓库 README 与 commit 历史（GitHub API）、Wayback CDX 里的邀请链接、官网首页、RDAP、彭涛博客。
  • 创始人、ZIMACODE LLC 注册地、真实收入未查到；用户数为自报。
