增长循环

有证据:

  • 替代品顺风：Soundflower 停更后，HN 等社区反复把 BlackHole 推荐为替代品，2020 年疫情期间集中出现。
  • 搜索占位：我方渠道数据搜索 51.3%，词是"blackhole""blackhole audio""blackhole 2ch""blackhole mac"，品牌名本身就是品类词。
  • 教程生态：引荐来自韩国 tistory、日本 note 等教程博客；README 自带 Logic、GarageBand、Zoom、FaceTime 路由教程。
  • 被其他产品依赖：Show HN 项目（如 Pluely）把 BlackHole 列为 macOS 系统音频方案；商业产品要么开源、要么买授权，把它当默认依赖。

推测:

  • AI 会议记录、转写工具（Recall.ai 类）兴起后，大量工具文档让用户先装 BlackHole，形成第二波需求。
  • Homebrew 一行安装让开发者圈子口口相传。

收入与规模线索

  • 收入来源：下载页 $10 打赏、GitHub Sponsors、商业授权、赞助商 Recall.ai、付费 App Dipper / Flash Metro。Patreon 只有约 $0.8/月，说明不是主收入。
  • 具体金额未查到。
  • 我方数据：美国 37%、英国 7%、澳洲 5%；直接访问 36.5%。

可信度与缺口

  • GitHub 时间、HN 数据、Soundflower 替代叙事有一手来源，可信。
  • 搜索结果几乎全无关（reddit 那组返回了"health"之类），只能靠 GitHub、HN 补证据。
  • 缺口：Devin Roth 个人背景、下载量、商业授权收入、Dipper 价格和上线时间。
