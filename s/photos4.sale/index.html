第一批用户从哪来：Allan Ure 本人在奥克兰周边越野跑/山地车/XTERRA 赛事上拍的参赛者——拍了谁，谁就会来站上按号码布找照片。最早的"客户"其实是愿意让他进场拍摄的主办方，参赛者是跟着赛事来的。

新用户从哪来：每多拍一场赛事就多一批参赛者；主办方赛后在邮件/社媒里发照片链接（引荐 10%），参赛者搜"photos4sale + 赛事名"（品牌搜索占搜索流量 83%）；Facebook/Instagram 每场赛后发帖。改成免费/PWYW 后，主办方更愿意引入（赞助商出钱可以把照片当参赛福利），赛事覆盖面扩大。

增长循环

有证据:

  • 赛事 → 参赛者：一场赛事数百到上千人，赛后都要来找照片（直接 + 品牌搜索合计约八成）。
  • 定价改造：2016 年起免费/PWYW，官网直接邀请主办方"了解在你的赛事上用 PWYW 模式"。
  • 赛事覆盖面：2015 年数十场 → 2019 年起扩到澳洲 → 现约 300 场。
  • 社媒每场发帖导流（Facebook 4.5k 赞、Instagram）。

推测:

  • 照片本身带水印/站名，被参赛者转发到社交平台时间接给站点做广告。
  • 越野跑圈子小、复参率高，同一批人一年跑多场，复访强。

收入与规模线索

  • 2014–15 年按张卖 $9.95–$22.95；2016 起免费 + PWYW，收入来自赞助商打包费和自愿付款，金额未公开。
  • 约 300 场赛事；Facebook 约 4,500 赞。无营收数据。

可信度与缺口

  • 新站，从零写。时间线全部来自 Wayback 原页面，可信度高；"创始人是 Allan Ure"只依据 About 页联系人和摄影师分组，未见访谈。
  • 搜索结果几乎都是无关内容（创业通用文章、病毒照片新闻），没有访谈、媒体报道或 Reddit 讨论。
  • 缺口：Allan Ure 个人背景、PWYW 后客单价/付费率、赞助商补贴模式的价格、员工数。
