增长循环

有证据:

  • 搜索占位：每款游戏、每个私服（如 Warmane）各有一个落地页，玩家搜"buy X gold/coins"时进来；我方数据 Organic Search 第一、Paid Search 第三；profile 档案中非品牌搜索词有 "fc 27 web app"、"facas mm2"。
  • 新游截流：新游上线即开"marketplace"，并在 Facebook 和官网资讯栏发上架公告和攻略（官网 news 栏大量游戏攻略/活动文章，同时承担 SEO）。
  • 联盟返佣：10% 订单佣金，面向 YouTube/Twitch/Facebook/Instagram 创作者，禁止投 Google/Bing 广告和优惠码聚合站。https://www.iggm.com/affiliate
  • 社媒抽奖 + 优惠码 + 节日促销（站长访谈自述）。
  • 软文/点评站：2024 年 eyesongame 访谈带广告位；多个 RMT 点评站（MMODude、bettergamer、boostingreviews）收录它。
  • 信任与复购：Trustpilot 18.6 万条评价、负评全部回复；积分（最多抵 10%）+ VIP（最多 95 折）+ 签到 + 回收（Sell To Us）。

推测:

  • 第一批用户来自团队此前在欧美 RMT 公司积累的客户、供货渠道和搜索经验（About 页暗示，未核实）。
  • 上 2–3 个月德国流量跳升，可能对应某款欧洲热门新游（如 EA FC 系列）或新开 Stripe 收款通道。
