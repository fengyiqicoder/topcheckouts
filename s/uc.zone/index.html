基本信息

  • 产品：Umbrella 游戏外挂订阅（Dota 2 为主：自动补刀、地图透视、换肤、自动钩子、800+ 功能；另有 Deadlock、CS2、Minecraft）。Lua 5.4 脚本 API（UC.Zone API v2，有 GitBook 文档，社区成员维护 GitHub 镜像），云端分享配置/主题。
  • 运营方：未公开；服务器在莫斯科（Safe Value Limited），2018 年用俄国的 Cloud-Shield 防 DDoS，支付接 Anypay。渠道：Telegram、VK、Discord（Umbrella 服务器约 3.2 万人）、YouTube。
  • 定价：免费试用（页面写 7 天/标题写 10 天）+ 月付/半年付（价格页未显示）。
  • 域名：uc.zone 注册于 2017-11-07（RDAP，注册商 101domain）。
  • 流量：俄罗斯 61%、波兰 6.5%、乌克兰 6.4%；直接 60%、搜索 36%（几乎全是"umbrella""амбрелла"等产品名）；引荐 vk.ru、funpay.com。
  • 注意：外挂违反游戏服务条款，本报告只记录其增长路径。

增长循环

有证据:

  • 脚本生态：Lua API 开放，社区作者持续写英雄脚本（2019 论坛起即如此，现号称 500+ 脚本），让外挂越用越强、用户留在平台。
  • 免费试用 + 免费日/折扣 + 促销码，降低首次尝试门槛。
  • 推荐码（referrer 参数）和第三方游戏交易平台（FunPay 引荐 1.3%）转卖。
  • 社群：VK（引荐 1.3%）、Telegram、Discord 3.2 万人、YouTube 演示视频。

推测:

  • 外挂类产品不能投主流广告，主要靠玩家口耳相传和 YouTube/VK 演示视频带来"umbrella dota"品牌搜索。

  • 价格未公开（页面占位"Infinity $"）；收入无线索。

可信度与缺口

  • 新站从零写。域名、论坛形态演进、渠道（VK、Digiseller、FunPay）有 Wayback 和第三方扫描页证据。
