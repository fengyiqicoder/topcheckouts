增长循环

有证据:

  • 开源 + "XX 的开源替代品"定位：GitHub 星数本身是社交证明，官网首页直接展示星数并号召"想自建 SEO 工具的人，在 OpenSEO 上建"。
  • 按 AI Agent 场景设计：MCP + skills 让用户在 Claude/Codex 里一句话装上，"复制 setup prompt"便于在开发者社群转发。
  • 托管版 $10/月 vs Ahrefs Lite $129/月，价格对比是主要转化话术。
  • 两次 Product Hunt 发布（上三个月当日第一；本月 fmerian 提交，第 2 名，384 票）。
  • 第三方内容自发传播：营销 newsletter、YouTube/博客自托管教程、TikTok 营销博主都在讲"免费替代 Ahrefs"，官方 Instagram 只有 158 粉，传播主要不靠自有账号。
  • 星数曲线：1.6k（4-27）→ 4.0k（7-04）→ 24.8k（10-25）。PH 首发前三个月只涨了 2.4k，之后三个月涨了 2 万多，起飞点就是 上三个月 PH。
  • 引荐：stripe.com、saashub.com、ycombinator.com（profile 档案）。

推测:

  • PH 第一后很可能上了 GitHub Trending，再叠加 X 上 AI Agent 圈转发和"awesome MCP"类列表收录，具体爆点帖未查到（X 无法抓取）。
  • 第一批用户：上六个月前的 1.6k 星推测来自创始人 X 账号 @bensenescu 和开发者圈（Show HN 只有 2 分，HN 不是来源），未证实。
  • 自托管用户遇到 DataForSEO 计费和部署麻烦后转托管版。

收入与规模线索

  • 3,000+ 用户（官网自述）；托管 $10/月起 + 按量充值，约 28% 加价转售 DataForSEO（第三方文章估算）。
  • 上个月收款页访问 47,278。

可信度与缺口

  • 星数曲线现有三个点，上三个月 PH 后加速有间接证据，但没有逐日数据。
  • 二次补查：补了 7-04 的 4,001 星基线，确认 PH 首发是起飞点；补了 本月二次发布的数据（fmerian 提交，384 票，第 2）和 上 1–3 个月第三方 newsletter、YouTube、TikTok 自发传播。增长引擎从"创作者供给"改为"主播或社区运营"：OpenSEO 不是 UGC 平台，旧标签用错了，实际传播靠开源社区和第三方博主自发转述。
  • Reddit 存档接口本轮限流，Reddit 上的首发情况未核实。
