基本信息

  • 产品：浏览器插件收款服务 + 开源 JS 库 ExtPay（MIT）：Stripe 收款、免费试用、一次性付费、订阅、登录识别付费用户；支持 Chrome、Firefox、Edge、Opera、Brave。
  • 创始人：Glen Chiacchieri（个人站 glench.com：前 MIT Media Lab Scratch 工程师、Dynamicland 前身团队研究员、2020 年转行心理治疗师；做过 Chrome 插件 Dictionary of Numbers）。看起来是一人项目。
  • 定价：免费注册，每笔交易 5% + Stripe 手续费（2.9% + 30¢），无月费。
  • 域名：注册于 2020-12-19（RDAP）；GitHub 仓库 Glench/ExtPay 创建于 2021-01-08；Wayback 首个产品页 2021-01-14。
  • 流量：台湾 18.6%、美国 17.4%、洪都拉斯 6%；直接 70%、社交 22%（WhatsApp、YouTube、Reddit）、搜索 4.5%；引荐 pokeathlon.com、gameforge.com——多为用它收款的插件/网站把付费用户导过来。

增长循环

有证据:

  • 开源库即分发：开发者在 GitHub 发现、复制 sample extension 即可接入。
  • 官方背书：Mozilla 插件文档直接推荐。
  • 付款页带品牌：每个插件的付费用户都会打开 extensionpay.com 付款页（流量里大量引荐来自插件/游戏站，台湾、洪都拉斯等国家占比高就是某几个插件的付费用户）。
  • 开发者内容：dev.to、CSDN 等教程/复盘文自发传播。

推测:

  • 开发者之间口碑（"不用写后端"）是主力；网站自己几乎不做 SEO（搜索仅 4.5%）。

收入与规模线索

  • 开发者累计收入（GMV）：$1.3 万（2021-11）→ $2.1 万（2022-01）→ $10 万（2023-01）→ $30 万（2024-01）→ $80 万+（2026-10）。
  • 按 5% 抽成，平台累计收入约 $4 万量级——推测；是小而美的一人副业。

可信度与缺口

  • 新站从零写。注册/开源/上线时间、GMV 里程碑都有 RDAP、GitHub API、Wayback 逐年快照硬证据，可信度高。
  • 缺口：首发帖（HN/Reddit/Twitter）未找到；接入的插件数量未公开；Google 关停 CWS 付费的确切日期凭记忆。
